# 地图物件美术补齐 · v6.2.0

本轮解决既有新增地图元素的材质断层：细致背景和人物旁，试炼、归灯、补给仍是平面图标，浮筏/碎台只在统一石台上加线，地刺是纯色三角。以现有山水、寺门、铜灯图集为参照，用内置ImageGen生成三张生产图集，并在游戏实际比例下重新切片接入。地图长度、敌人、奖励、交互和存档规则保持原样。

基线为`codex/ranged-hero-v6`的`59b91e0b1fa2754067b800dbba83f4111514703b`；本轮分支`codex/map-art-v6`。

## 物件设计与判断

| 既有内容 | 实际美术处理 | 玩家应能看清的区别 |
| --- | --- | --- |
| 试炼 | 铜石小龛、三根立棍、残朱带、莲座香炉；四状态使用同一尺寸和地面锚点 | 金色待启、紫焰战斗、玉光可领奖、暗铜已领；F行为与原来相同 |
| 归灯 | 细铜柱、檐顶灯笼、石莲底座，替换平面黄方块 | 灯芯明灭与一次性使用对应，不靠颜色换皮更换物件外形 |
| 三类补给 | 翠玉药葫芦、莲托定心珠、铜爪战意焰 | 轮廓分别为葫芦、圆珠、火焰；满值降低亮度但保留物件，自动拾取区域不变 |
| 普通地面 | 山道苔石、古渡湿木、残庭灰石；对应墙基纹理 | 统一落脚边缘，材质表达所在区域，地面下方不再是大块平涂格线 |
| 碎台、浮筏、接桥 | 破损支撑与裂缝、绳扎木筏与铜环、断开的冷石/连通的玉缝 | 碎裂从细缝变深缝再消失；浮筏随真实位置运动；未接桥没有连续亮边 |
| 地刺、阵界 | 黑莲石刺三状态、铜石莲柱 | 闭合暗瓣→亮缝预警→尖晶激活；地刺贴图裁在原危险框内，阵界以实物标记代替竖向虚线 |
| 延长路线 | 松根石塔与残块、朽木系缆与弃灯、残碑香炉与倒坛 | 小体量、冷暗、不发光的路边遗物；与明亮归灯、奖励、敌招区分 |

视觉沿用青灰石、朽木、旧铜、朱砂布、琥珀灯火。友方和奖励使用温金/玉青，地刺危险使用玫紫；角色、危险边缘和落脚面优先于装饰纹理。既有敌招的精确预警线、资源条和短粒子继续按状态程序绘制，位图负责物件主体与材质。

## 实际比例和接线

- 游戏Canvas保持960×540；固定像素模块与nearest-neighbour采样，不用整张图拉长铺满关卡。
- 试炼主体约82像素高、归灯约80像素高；角色旁能看清檐、灯芯和底座。拾取物高22–24像素，并保留原来的小幅浮动。
- 地面顶模块64×30、筏96×30、桥64×24、墙基64×64；裁掉末块多余宽度。明确的1像素落脚边缘与模拟`platform.y`一致，绘画的下挂结构不改变单向平台判定。
- 地刺模板32×16，静息/预警/激活在现有13像素高危险框中呈现不同高度；不会把画出的刺尖延伸到判定框之外。
- 四个试炼状态和两盏归灯共用缩放与底部锚点。源图行距不均，使用明确源矩形，不盲切等格；三类拾取物按各自轮廓归一到独立32像素小格。
- 装饰按已有`room.landmarks`选择。初次接入发现部分地标在断崖边，现仅把装饰落点夹到邻近实地上，最大挪动160像素，避开归灯、阵眼和地刺；不修改地图平台、存档或标记坐标。

`src/map-data.js`是切片与锚点，`src/map-art.js`负责材质、物件、状态与低层装饰。旧journey/progression的几何主体仅作为素材未加载时的回退。`renderer.js`增加地刺绘制钩子，原判定仍在既有模拟中。

## 素材、提示词和复现

- `assets/map-v6/props-source.png` → `props.png`：试炼、归灯、补给、地刺。
- `assets/map-v6/terrain-source.png` → `terrain.png`：区域地面/墙基、碎台、筏、桥、阵界。
- `assets/map-v6/dressing-source.png` → `dressing.png`：三境的六组遗物。
- **完整最终提示词与引用角色**：`assets/map-v6/prompts.json`，全部使用内置`image_gen`；没有切换CLI或模型。
- `tools/prepare-map-art.py`用Pillow做裁切、nearest-neighbour尺寸归一与拼接；`normalization.json`保存源SHA、透明像素计数、每个源矩形、共同缩放、锚点及成品SHA。保留生成RGBA，不用黑色键抠图，不手画替代主体。
- 第三张生成图的预览曾显示底层RGB渐变；实际在游戏底色上的alpha合成检查无矩形背景，透明像素887820个。该检查图保留在`evidence/map-v6/dressing-alpha-check.png`。
- `tools/pack-art.cjs`只打包三张归一后的PNG；合计243597字节，内嵌到发行HTML，不在运行时读源文件或调用生成接口。打包清单为`assets/map-v6/pack-manifest.json`。

设计判断以实机截图为依据：`before-camp.png`和`http-ferry.png`显示归灯、湿木地面和系缆；`before-trial.png`和`after-trial.png`显示试炼主体与地刺。前后对照使用固定种子和同一Canvas画面条件；完整交互截图另保留HUD和提示。功能验证与审美判断分开，具体见VERIFICATION.md。
