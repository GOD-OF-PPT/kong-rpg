# v6：掷环借势

基线v5.0.0 / `15cdff7fa331f4c8a11ebcafaaac7fd7ecea8328`，分支 `codex/ranged-hero-v6`。保持现有Canvas、四关、三境守关与构筑规模，增加一位可选应劫者及针对远距站位的敌招。

## 原始依据与选择

直接阅读维基文库《西游记》[第四回](https://zh.wikisource.org/zh-hans/西遊記/第004回)、[第六回](https://zh.wikisource.org/zh-hans/西遊記/第006回)，来源文本保存在research/。第四回写哪吒年轻的外貌、六般兵器及“百千万亿照头丢”；第六回杨戬描写为“腰挎弹弓新月样，手执三尖两刃枪”。这说明两者都能支持远距输出；不把这些小说段落冒充《西游记后传》原剧观看记录。

|方向|玩法价值|取舍|
|---|---|---|
|杨戬：弹弓/法矢与天眼|瞄准与穿透弱点，操作直观|需要另建弹药/弱点体系，容易变成站定连续射击|
|哪吒：掷环、回程、绫缚|同一环的去回路径随玩家换位改变；一次出手有回收空当|选择实施；限制为一环在外，靠站位取得两次命中|

乾坤圈、混天绫为大众神话形象的采用，具体伤害、回旋规则、绫缚区域和应援剧情均是本游戏原创。未取得后传原剧对应片段，不编造集数或时间码。尝试访问封神原文具体回目未成功，故不将其列为已核实文本。

参考[Dead Cells Update 19](https://deadcells.com/patchnotes/19)开发者原记录：双手弩重做同时涉及主副手和装填，冰片则移除弹药以明确副武器身份。提取的方法是同时约束攻击、空当及辅助能力；本项目不照搬装备数量。没有声称亲自游玩该版本。

## 规则

- 哪吒J水平掷环，左键朝光标自由瞄准；环出手约0.14秒，一环在外不可再掷，去程约360像素、回程追随玩家。去回程各结算一次，前盾可挡，绕盾回程可打背。站得远不会突破最大射程。
- L混天绫消耗定力，在前方短时绫缚区域打断一次普通蓄力并减缓敌人位移；不会持续冻结敌招。R莲火轮阵使用100战意，起势护体、后段可受伤。保留Q符术、K闪避、下劈与平台移动。
- 六舍利与现有成长按角色解释：破甲环增强回程破盾；绫缚强化替代分身强化；远距余焰强化回旋折返点。每项都要有实际生效规则和对应详情，不出现无效奖励。
- 悟空仍能选择，保留近战连棍与分身。

## 敌人反制

距离触发针对的是站位，对两位角色统一生效，避免敌人暗中读取角色获得免疫。

1. 执刃魔兵：远距锁定一条地面突进路径，充分预告后冲至锁定位置；受地面边缘限制；可跳、让路或重击打断，收招给远程再掷窗口。
2. 重盾兵：举盾逼近，正面挡圈，方向在动作开始锁定；玩家可腾越、借回旋打背或等收招。没有远程伤害免疫。
3. 莲灯使：远距离交替使用锁定位置的交叉落印；预告后不跟踪，留一侧撤离通道；玩家须改变站位而非永久后退。

## 在验证前确定的条件

- 两名角色都能通过菜单/键盘选择，HUD、技能说明、奖励效果和结算身份一致；存档明确保存角色和飞环/绫缚中间态，旧档继续旧版。
- 一环不能重复刷伤；去回程能各命中一次；盾正面能挡，换位能打背；环不能绕过关卡锁或无限飞行。自由瞄准需要实际鼠标验证。
- 三种反制招式有足够预警，实际判定与标记一致；同场固定种子，站定连掷和观察预警后换位的受伤、输出、定力消耗有可复核差异。不存在无解必吃伤。
- 悟空既有规则回归；哪吒完成一次HTTP及关闭服务器后断网file的完整键鼠胜负闭环，另以合法导入场景复核关键敌招、存档、奖励和焦点。
- 美术使用ImageGen统一六姿态，按共享比例与脚底锚点规范化，再以实际尺寸检查跑、跳、出手、受击和回环轨迹。图片每次只检查1–2张。
- 无真人条件时只报告自动操作证据；不声称已验证首次辨识、耐玩或重开意愿。
