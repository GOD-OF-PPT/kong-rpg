# 如意与风火 · 实际美术

使用内置`image_gen`，没有CLI替代。源PNG、归一PNG与完整最终提示词均在`assets/signature-v7/`，引用既有悟空/哪吒图集作为身份和服饰约束。三次小批生成后分别检查，再接入实机。

- `wukong-source.png`：四姿态共一张2×2图，蓄力、水平伸刺、收势、撑跃。保留猴相、双红翎、金甲青衣与朱带；手中只留短铁柄，防止旧整根武器与新伸缩棒重复。
- `nezha-source.png`：起飞、悬停、前飞、收轮共一张2×2图。双髻、朱绫、青裤与旧金甲对应原角色，两只铜火轮分别承在脚下，投环手掌空置，游戏里的实体飞环独立绘制。
- `fx-source.png`：乌铁棒身、固定金箍、棍尖火花、风火尾、空印预警/爆开、盾势徽记、蓄力光。棒身按像素模块重复，金箍不随距离拉长；棍尖金色虚线标出伤害甜区。紫色莲印采用透明中心和精确矩形边缘，保留实际危险范围。

`tools/prepare-signature-art.py`按源透明包围盒裁切，人物共用缩放，靴/轮底部共用锚点；nearest-neighbour归一到128格，身体约82–84像素高。归一脚本不重新绘制像素，不用色键删除黑色；源图原alpha保留。`normalization.json`记录源SHA、透明像素和切片，`pack-manifest.json`记录入包图集SHA。

新帧的脚/轮底部对齐模拟脚底；前手按各姿态给出棍身连接点，棒长与实际碰撞取自同一个`K.staffLine`。撑杆接触点是平台真实坐标，起跳后棍端仍留在接触点；不会用装饰假装存在平台。轮火尾流只有脚下短距离，危险框及敌招提示保持上层可读。

`src/signature-art.js`只读模拟状态；姿态、杆身长度、收招、空印位置与模拟时钟一致。声音复用既有WebAudio风声、升调和已嵌入ElevenLabs重棍采样，不在运行时调用接口。HUD与B详情、手记、角色选择均说明U操作和轮火/蓄力状态。

本轮是关键姿态切换加连续杆长/轮火表现，不声称全套逐帧动画。实机原图和录像见`evidence/signature-v7/`，最终验收边界见VERIFICATION.md。
