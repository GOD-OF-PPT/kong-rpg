## 观察链

原文可伸缩武器 → 距离由玩家主动决定 → 蓄伸/棍尖/收招 → 玩家先量距离，追求棍尖破盾或改撑跃 → 棍尖与棍身对同盾兵的不同结算、真实撑地、取消不返定力。

原文双轮迅捷移动 → 空中位置可以主动经营 → 短时驭轮/投环/落地回充 → 在轮火耗尽前决定继续飞、换角度或落下 → 同一空印中悬停受击、收轮下降避开；重按U不补燃料。

官方手册的独立空中操作和魔法限制 → 移动/攻击/资源形成选择 → 原三连、分身、绫缚和新能力竞争定力 → 低思考策略不应稳定优于观察策略 → 固定盾兵+法师、相同初始资源、三类输入策略与两套初始舍利比较，保留失败策略与初版控制器。

不选无限飞行与随按即满长：现地图已含可选上路、地刺与盾兵，这会让原判断失效。没有为新招另加地图、敌人血量或不可绕过的技能门。新招都能被已有跳跃/闪避/换位应对，敌方响应采用可见锁定时间和收招。
