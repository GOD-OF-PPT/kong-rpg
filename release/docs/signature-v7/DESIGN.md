# 如意与风火 · 制作目标

目标体验：悟空用棍长与撑地改变交战距离，哪吒用有限轮火改变投环角度；敌人以提前锁定的冲阵/空印回应，玩家靠判断位置和收招取得收益。

比较方向：自由伸棍/无限飞行直观但会让平台、盾兵和地面危险失效；选择“蓄伸点刺/真实撑地”和“短时驭轮/落地回充”，保持既有三连、跳跃、分身/绫缚和舍利之间的资源竞争。地图与四关闭环沿用现有内容。

## 实施规则

- 新增统一U键。悟空按住U蓄棍，松开水平伸刺；10定力起势、每秒24定力蓄长，最多0.6秒。棍身伤16，蓄满一半以上的末端甜区伤34并破正面盾、打断普通蓄力；定海心加宽甜区。射程100–320，收棍及恢复期间不能连发。K可取消，已花定力不返还。伸棍普通命中不返定力，须回到三连或借破阵/击杀续回，避免远距自循环。
- 悟空松开U时按S改为撑跃：棍端必须触及当前可站立平台，短暂撑杆后弹起。撑跃舍弃本次伤害，一次腾空仅可撑一次，落地复位。没有实地就没有凭空升力；腾云骨仍可接空跳。
- 哪吒按住U踏轮起飞，AD换位，W/空格升、S降，松开收轮。8定力启动、每秒20定力，轮火1.25秒，凌云踵为1.5秒；落地且松开U后回充。空中重新踏轮沿用剩余轮火，并再次支付启动消耗。飞行可掷环；没有无敌。K、R、下劈或受伤会终止飞行。
- 盾兵面对远处蓄棍会先标出路线再冲到锁定位置，起势0.8秒、收招1.3秒；可跳、撑跃、闪避或用棍尖破势。法师对高处目标预先锁定一枚空中莲印，0.95秒后爆开；落下或横移可避，预警之后不追踪。两者沿用原生命，不靠加血或瞬时命中增加难度。
- 复用既有构筑：定海心扩大棍尖容错、腾云骨支持撑跃接空跳；凌云踵延长单次空中轮火，破甲环仍需要安排回程路线。原有法门与限次符术继续消耗本局选择。

U与DOM菜单隔离；暂停/导入时蓄棍不得因清空输入自动射出。伸棍、驭轮、敌招的中间状态需可保存恢复；新规则使用schema7/独立存档键，并保留v6.2.1原入口和旧档，避免更换旧旅程规则。

## 验证门槛（实施前）

1. 相同种子、盾兵/法师遭遇、相同定力，比较连按、只蓄满/一直飞、读预警改变距离/及时落地。记录承伤、清场、定力与招式时机，不以单次胜率证明乐趣。
2. 棍身与金色棍尖命中不同；每次伸刺只结算一次，不能隔空撑跃；轮火不能由空中松键、踩敌、读档无限恢复。
3. 新敌招锁定后不追踪，预警轮廓覆盖实际判定；有原技能和新技能两类以上可行应对。
4. 真实键鼠完成U蓄放、S撑跃、U升降/掷环、取消、暂停、奖励、读档、死亡和新开局；两角色完整四关，HTTP和全新断网file入口。
5. 像素姿态、可伸缩棒身/金箍、双轮及风火尾流、莲印警示实际入场检查。逐小批审查源图和实机，不以概念图代替交付。

本轮尚未核对《西游记后传》原片的新动作片段，伸缩/撑跃/轮火限制及新敌招均为游戏原创，不冒称电视剧中的具体战斗复现。
