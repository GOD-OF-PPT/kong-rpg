# 外部试玩观察方案（尚未招募/执行）

目的：观察陌生PC玩家能否通过预警和失败改变操作，而不是验证他们能否听懂设计者讲解。3–5人仅用于发现具体问题，不作总体统计结论。不擅自联系或发送邀请。

准备：同一版本哈希、种子LOTUS-1025、未使用的新档、本地离线包、键鼠与录屏。允许看游戏自身的开篇和提示，不额外讲解解法。

1. 第一轮静默观察。记录第一个误判落点、第一次受伤、第一次舍利选择。不要在失败前提示正确动作，也不要一边要求反应一边不停提问。
2. 失败或一次遭遇结束后再问：「你刚才看到了什么？」「你认为伤害来自哪里？」「下一次准备改变什么？」先记原话，再核对实际记录。
3. 同样局面再来一次，观察玩家是否真正改变输入、落点或神通时机；不能仅凭“我懂了”算通过。
4. 初始舍利按AB / BA顺序交替安排腾云与照影，避免所有人都在第二次拿到更熟悉的版本。第二局允许自由选择，记录选择和理由，不强迫轮换全部技能。
5. 结束时询问是否还想再玩；区分口头回答与实际自愿点开第三局。不要以测试者配合重开当作留存证据。

记录字段：匿名编号、平台经验、版本哈希、构筑顺序、种子、录像时间码、可见预警、实际输入、伤害来源、事后解释、下次动作、重复局面结果、自愿重开、原话备注。

需回到开发的问题：玩家反复指认不到伤害来源；预警与真实有效区域不符；同一低思考动作在多个不同局面都无代价占优；换舍利只改变数值而不改变位置/时机；失败后没有可执行的新想法。

没有真人参与时，本项必须保持“未验证”，不得把脚本、设计者自评或本文件视为试玩结果。
