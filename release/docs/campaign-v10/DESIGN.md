# 五界旅程：关卡、首领与评分

五章按云上→地府→水下→龙宫→天宫展开，共十五张实际布局。每章第一关以近战/远射辨识为主，第二关增加高低站位与盾兵配合，第三关缩短路段、集中首领战。三类结构并非简单复制：章节改变断口位置与宽度、悬台高度/宽度、地面危险周期、敌人位置和法术；十五组平台布局互不相同。地图背景/地表沿用五领域已完成资源，新增敌人和首领资源。

## 大首领机制

|首领|三招|可观察的代价与反制|
|---|---|---|
|巨灵神|断云重斧、踏云震、横斧冲阵|重斧固定方向后可跳避/绕背；震波限制低位；冲阵先画实际路径。出招后落斧收势1.65秒，追击窗口稳定。挑战偶数轮追加一次重新预告的攻击。|
|秦广王|朱笔定罪、缚魂锁道、追魂复判|两张判牒在起手时护体，未收招时伤害降至55%；任何主副武器可破牒撤甲，也可等收笔全额追击。追魂复判第二次锁定玩家当时落点，需要第二次判断；不能只离开第一印。|
|九头虫|九首毒扇、污潮横涌、九首俯冲|毒扇三层弹道预告，层间留隙，可改变高度/返弹；低潮波起跳；俯冲路线锁定且带长收招。不会用临时无敌要求特定技能。|
|东海龙王|双龙水柱、东海潮涌、龙角雷诏|水柱同时锁两个落点，雷柱留下可移动空隙。潮涌蓄力时出现28生命潮珠，击碎可打断并给2秒破绽；也可保留资源、跳过潮线后追击。下一次潮涌会重聚新珠。|
|托塔天王|天王断邪、七宝镇阵、塔火轮潮|剑锋看向可绕背；塔基36生命，任何武器击碎会撤去镇压柱并给2秒破绽。二轮召出两名固定塔兵，计入生存威胁但不计歼敌分；塔火轮可跳或返弹。|

十名小首领拥有各自精灵和两招组合：云上教重斧/震地及风射/冲阵，地府教印区/锁道及复判/远射，水下教盾冲/潮波及扇毒/俯冲，龙宫教甲阵/水柱及潮涌/雷印，天宫教远射/火轮及剑势/塔阵。具体名称与顺序见README表格。

普通怪不是只换血量：每章三个独立轮廓，近战接近与短斩、远程锁定/章内法术、盾兵正面防御与冲击。第二关改变三者比例和高低部署；第三关少量护卫在首领之前消耗资源。普通模式最多两个附近小怪同时蓄力；挑战放宽到三个，每关增加三名固定援兵，并让首领偶数轮追加独立预告的追击。生命不统一倍增，危险几何始终在锁定后保持稳定。

## 评分与资格

完成十五关才授予通关评级资格。总分 = 时间分 + 避伤分 + 歼敌分：

- 时间分：max(0,35−max(0,游戏活动秒数−1500)/30)。25分钟内35分，之后每分钟扣2分。暂停、奖励阅读与参悟对话不推进活动计时，战斗中的停顿计入。
- 避伤分：max(0,40−0.5×实际受伤次数)。以成功扣血事件计数，不按伤害数值；无敌/护体挡下不计，坠落扣血计一次。
- 歼敌分：25×唯一计分敌人击杀数/本模式固定计分敌人总数。普通110，挑战155；单次旅程以关卡ID+敌人ID去重，重复伤害/召唤物不增加分数。普通怪可绕过，分数会降低。
- 总分保留一位小数，S≥90、A≥75、B≥55、其他C。失败页面只显示当前估分，不能授予解锁。

严格“高于A”解释为S。普通完整十五关S在结算时写入资格凭据；菜单、开始游戏、重开和挑战存档恢复均检查凭据所含关卡完成/难度/用时/受伤/击杀能否成立，而非单个可随意翻转的界面布尔值。离线客户端不宣称防人为改档；目标是避免正常流程、旧档、失败记录或A级意外解锁。凭据随导出/导入携带；导入较早普通旅程不会清掉本机已取得的资格。

## 资源与状态边界

新图像由内置ImageGen生成并复制到工作区；五Boss图集与五章兵种图集，50个登记切片。Boss图集关键姿态配合位移/蓄力/命中特效，不宣称完整手绘逐帧动画。首版巨灵神长条和抬斧格有顶端裁切，未纳入运行时；完整的待势/砸斧/冲阵姿态用于正式版，待势兼作蓄力底姿。部分源图披风越格，通过明确裁切和连通主体选择清除相邻角色残片，再使用最近邻与共同比例、脚底锚点归一。原始RGBA与来源SHA保留在normalization.json，提示词在PROMPTS.md。

schema10与独立存储键保护新规则；v9发行HTML原样保留。存档包括章节进度、唯一击杀、受伤、资格、机关生命/命中去重、敌人锁定区/二段招式、角色武器与秘技施展状态。F交互已切断原四关阵眼的兜底入口，避免空场F读取不存在的阵眼。
