# 玩法与像素表现依据

## 实施的取舍

比较了继续累加奖励和三槽舍利替换两条方向。选择后者：维持六枚舍利与三境规模，但让成长产生放弃。腾云改善高位路线，照影消耗更多定力换驻留远程压制，定海心要求把第三棍留给破盾/打断。补给是同一次奖励中的选项，恢复资源就放弃这次换法。

每次遭遇的判断是落在哪里、敌人正在举刀还是收招、是否用定力争取绕背。棍法短连可随时开始，但第三棍收招更长；闪避短暂无敌但有冷却；分身驻留且消耗40/50定力，不会跟随本体。重复游玩的变化来自种子、上层补给和三槽组合，不来自更高永久属性。

## 原始观察到规则

|当前版本的原始观察|实现|预期行为与检查|
|---|---|---|
|v1.2 连按在较远位置能先击倒近战敌人，近身会吃一刀|保留轻棍不冻结敌招；扩大可读的近身起招范围；重击打断仍有锁定时间|固定第一遭遇 x380/390 比较连按与读招，保留远距轻棍可以有效的解法|
|v1.2 无天护体为全身免伤，等待收招才能输出|正面40%伤害，背后与收招100%；移动前先预告，再实际移形|玩家可选择安全削血或冒险绕背，避免全场只等待；规则和动态画面检查|
|无招式时身体相撞也扣血，容易混淆受伤原因|普通贴身挤开，伤害由已预警的攻击结算；移形冲撞仍是伤害|受伤日志能指向斩击、莲焰、地刺或坠落；伤害边界共享给渲染|
|旧三境地形近似、成长无限叠加|复用已保存试作的三段独立布置；每境两阵，三枚上限与明确替换|经过同一段时可以改换空中、驻影、反弹或调息选择|
|原美术只有一个奔跑姿势，阵眼与莲灯使轮廓相似|新增跑动序列与独立黑莲阵眼、补给灯、山门图集|实际尺寸与动态录屏检查轮廓、脚锚、预警和物体用途|

本轮复用试作时另外修复：远处敌人计时长期变负导致存档被拒；v1.2 schema2 被误判为新旅程；解压到任意目录后旧入口错误；键盘Tab先暂停再进入DOM，手记返回原界面。

## 美术执行

沿用已选的“劫后佛国”：青灰山体与旧佛国建筑、氧化金、朱红巾带、黑紫莲灾。画布960×540，角色站立约65–70画布像素，碰撞体24×44；金箍棒、巾带是轮廓附属，不当作身体判定。背景压低局部对比，平台金色亮边精确位于可落脚的碰撞顶边。

使用内置 image_gen，原始输出复制到 assets/art-v2。跑动图不完全服从等距格子，因此用六个明确源矩形与躯干/脚部锚点，不按网格粗切。以位移驱动帧序，停止时停回待机；图集全程保持透明alpha。攻击保留准备→生效→收招，生效阶段与攻击框共用 .055–.18秒。声音来自本地WebAudio，命中35ms暂停只服务于打击反馈。

黑紫水晶莲是需破坏的阵眼，暖金色供灯是可借灯的安全节点，青金山门是过境目标。预警用金色举刀/粉色地面路径和锁定瞄准虚线，实际攻击用亮红粉线；友方分身染青。文字、伤害数字、菜单均由DOM呈现。

当前跑动六帧中对应左右步的轮廓仍接近；敌人动作仍主要是关键姿势切换，尚非全动作逐帧精修。背景仍是合成整景，不冒充独立分层视差。

## 来源边界

角色、剧情冲突的题材来自《西游记后传》；动作规则、地图与收束为游戏原创。此前原剧候选视频未能成功观看的边界仍成立，详见 docs/RESEARCH.md。本轮没有新增可核实的原剧集数/时间码，不将二手简介当作动作来源。生成素材和现有源码是本轮直接检查的材料。
