# 棍影与回环 · ElevenLabs 打击音效 / v6.1.0

目标：让玩家能从声音区分挥空、有效命中、盾挡和重击。保持像素动作的短促反馈，不使用拖长的电影式爆炸覆盖下一次预警。

| 动作 | 声音设计与实际接线 | 代价与取舍 |
| --- | --- | --- |
| 轻棍 | 木质裂响、短铜棒实体；命中事件播放两条剪辑变奏 | 230 / 210 ms；挥空仍是独立合成风声，不伪造命中 |
| 第三棍 | 更厚的低中频和短石甲碎响 | 380 ms；仅重棍结算时播放 |
| 格挡 | 短金属咔响 | 280 ms；删去原素材约934 ms前置空白；Boss护体的削血声不再叠普通棍击 |
| 乾坤圈 | 铜环高频短鸣 | 290 / 300 ms两条变奏，普通环命中触发；破甲回环仍按已有重击事件发重击声 |
| 下劈 | 重棍原素材降速、低通，落点更沉 | 440 ms；这是剪辑派生音，并非第六条AI生成；落地范围伤害共用一次声音 |
| 大神通 | 低中频实体加短促爆裂尾 | 550 ms；每一波一次，不按受击目标数播放 |

没有改变命中帧、伤害、敌招、构筑或存档规则。`simulation`既有事件驱动音频；`app`按同一模拟步成组交付，合并同一次下劈、大招、阵眼与敌人结算产生的重复声音。跳跃、闪避、出招、预警、受伤、界面和背景音乐继续使用既有WebAudio合成音。

## 来源与编辑

- [ElevenLabs工作流](https://elevenlabs.io/app/flows/v8fj02jOm6mPw1Ry64T5)，模型 `eleven_text_to_sound_v2`。
- 共取得五条完成的原素材，每条50 credits，结果返回总计250 credits / USD 0.025。其余候选遭服务限流；未把失败请求计作成品，未重跑已完成素材。
- 原始提示词、generation ID、费用在 `assets/audio-v6/provenance.json`；原MP3在同目录`source/`。没有保存签名下载URL或账户凭证。
- 八条发行采样为32kHz单声道PCM16 WAV；配方、源/成品SHA、峰值、RMS、起音阈值在`manifest.json`。两条变奏是同一生成源的滤波/速度编辑，不冒称独立生成。
- 编辑复现：`python tools/prepare-audio.py`，需要ffmpeg与numpy；日常`npm run build`直接使用已处理WAV，不需要Python、生成接口或网络。
- 起音5%峰值阈值为0.062–2.062 ms；每条有0.5 ms淡入和衰减尾。原素材解码峰值曾超过1，编辑在浮点域归一化后写PCM，保留原文件供复核。源音本身是否有听感失真仍需人工试听。

## 播放与离线

`pack-audio.cjs`将WAV字节内嵌；用户手势解锁AudioContext后`decodeAudioData`，从内存播放，不fetch音频。首次未解码完成或浏览器解码失败时使用既有合成音回退，不延迟补播造成错拍。正常验收路径回退计数为0。

音效独立总线、压缩器和末端安全幅度曲线；轻击/环击短间隔合并，最多六个活动采样，优先保留重击和大招，替换时12 ms淡出。音量沿用原设置，平滑更改；进入暂停/DOM界面停止采样，暂停中按J不攻击。`__KONG__.audio()`提供只读诊断，不提供修改游戏状态的入口。

`release/sound-check.html`是内嵌资源的独立试听页；`assets/audio-v6/impact-reel.wav`依次展示轻棍、重棍、格挡、飞环、下劈、大招，中间留空。素材试听与游戏混音不同，先降低耳机音量。
