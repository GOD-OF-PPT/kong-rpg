# v3 设计与调研依据

基线009303f（v2.1，干净工作区），新分支codex/combat-and-world-v3。保留像素横版、三境六阵与舍利三槽；此轮用户明确要求丰富地图、敌招和剧情，因此增加的是可互动的地图内容与后果。

## 直接观察

原版同种子V3-COMBAT、人物x380的键鼠录像和截图保留在evidence/combat-v3/before.*。代码中轻重命中都使用同一hit粒子与35ms停顿；三连主要共用一张出棍图，伤害数值过小且与背景对比不足。三境的破阵→山门循环缺少世界事件，敌兵主要沿用普通斩击/盾撞/飞弹。

## 三项实现与取舍

### 打击动效

|原问题|实现|实际检查|
|---|---|---|
|三棍看起来相同|平刺、上挑、重砸各准备/接触/收招三姿，共九个原画关键姿势|游戏比例联系表、实际键鼠出棍录像|
|轻重命中同一粒子|四帧轻击星芒、重击碎金、青色盾挡、落地冲击图集|小批检查透明图集与实战截图，不能只看生成图|
|统一35ms停顿|轻击18ms，重击58ms；效果按真实模拟步衰减，停顿中仍向外消散|相同伤害目标，比较停顿和反馈类型，不靠增加血量造区别|
|一击全身白块、数字不清|减弱受击白染，短位移回弹、明确金/青/红数字，重击数字单独增大|命中、盾挡、受伤与下劈场景|
|声音近似|棍风分三段，轻/重命中分别下降音高和低频/噪声，反弹与破势用独立声型|本地WebAudio触发可运行；真人试听仍未取得|

第一棍有效窗45–145ms，第二棍75–195ms，第三棍120–255ms；每击只结算一次同一目标。第三棍更重但前摇和收招更长。取消/闪避与已有构筑关系延续，不添加武器菜单。

### F交互

新版所有输入映射、Canvas可访问说明、指南、地图提示与当前README统一F。实测E不触发、F能借灯/过境/开事件；旧入口保留其当时的按键，防止改变旧旅程。

### 内容与故事后果

|地图|新增内容|选择与后果|
|---|---|---|
|雾隐山道|旧寨牢笼、两名守卒、上层裂台|可救困或赶路；救困须战斗，完成后本境地刺消失并补给。笼门打开，人站到笼外|
|悬灯古渡|移动渡船、灯枢、三处可接回断桥|花20定力永久点亮本境桥面，或保留神通资源继续跳渡；桥面是真正的碰撞面|
|灵山残庭|节奏地焰、裂台、镇莲钟、三名守钟众|可叩钟并战斗，完成后无天落火少一处；也可略过，以更强风险面对终战|
|黑莲法界|三处锁地落火，叩钟后两处|预告固定落点后才生效；离开莲印、跳台或利用空当输出。前面救人/接桥/叩钟写入尾声|

裂台站立650ms后坍落2.8秒再恢复，基础地面路线仍在。渡船沿现有水道往返并携带站立者。地焰有安静、650ms预告、生效三阶段。没有扩大地图长度来填充时间。

普通兵保留原生命：刃38、盾60、无天270。后段刃兵突进斩与普通斩交替；盾兵蓄势冲撞后有较长收招；莲灯使隔次锁定地面；无天每第三轮落火。预告画面与实际区域共享函数/数据，普通重棍和踩踏可打断蓄力。玩家必须判断位置和时间，技能不是强制轮用。

## 存档与发行

v3使用独立键kong.black-lotus.v3与schema3，保存任务状态、见闻、守卫、地面危险、裂台/渡船时钟。旧v2键不覆盖；新包提供字节一致的legacy-v2.html（v2.1）及legacy-v1.html（v1.2）。导入旧档会引导回其原版，避免在进行中战斗中换规则。

发现并修复的实际问题：高编号守钟法师继承了过长的初始计时，导致刚进入第三境的存档被拒；修正后四境初入与事件中途均可恢复。持续按下劈曾每步重启动作，现已锁定到落地。浏览器检查不把导入失败后的旧画面当作新场景。

所有图由内置ImageGen生成并随包提供；全部脚本、样式和图像内联，无运行时网络生成。最终验收在VERIFICATION.md，外部真人的手感、剧情偏好与音效评价不由脚本代替。
