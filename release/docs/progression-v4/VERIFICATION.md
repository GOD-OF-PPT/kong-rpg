## 发现与修正

- 独立场景中，原地站在封愿光柱内会受伤，提前选定横向空隙可无伤避开；一味往Boss身体方向走可能被挡在另一道光柱内。预告锁点后仍有取舍，不要求轮流交齐所有技能。
- 图集第三行的兵器相连，已排除这些帧；前两行采用统一比例和实测脚底锚点。Boss躯干判定调整为88高，与脚底和主体位置对齐。见 `PROMPTS.md`。
- 增加成长摘要后，1320×760曾挤出底部提示；将紧凑布局阈值提前到1200，并增加整组选卡及提示同时可见的检查。
- 整局检查发现原有下劈状态在受伤后未中断，会让向上的受伤反弹持续漂移。`interrupted-slam-before.json` 保留了当时的坐标序列；现在受伤终止下劈并恢复重力，实际落回地面，存档拒绝相互矛盾的下劈速度。
- 构建器统一LF换行，与 `.gitattributes` 一致；发行提交另核对Git对象与manifest，避免工作目录和克隆后的入口哈希不同。
- 完整断网尝试发现：持续按住左键攻击，胜利弹窗出现后松键可能误确认。`held-pointer-before.json` / PNG保留当时记录。现在跟踪战斗按下的鼠标按钮，吞掉跨越模式切换的旧松键点击；新的一次点击和键盘确认照常生效。`pointer-result-safe.png` 及真实操作检查验证了结果。
- 控制器记录也出现奖励误取、满战意却死于盾撞，以及大招期间发送F后等待原地的情况，分别保存在 `held-space-before.json`、`controller-death-before.json`、`controller-interaction-before.json`。独立检查从战斗按下Space、F开菜单后松键，含同时按住鼠标的场景，均保持奖励未选。输入记录 `controller-stale-batch-input.json` 显示：F已打开奖励后，控制器仍发送了同一批Space，触发了按钮的标准键盘确认。控制器现在最后发送F，并在新按键之前复核界面；也增加W跳跃选项、F与R的时序处理及普通遭遇保命策略。这些记录用于定位问题，不作游戏或玩家胜率统计。

## 反馈、画面与测量边界

环境：Windows 11专业版10.0.26200，Intel i5-14600K，Node22.12.0，Playwright1.62.1，Edge156.0.4314.42，headless。完整操作视口1440×1000。

完整流程的rAF帧间隔p95：HTTP 5.7ms / file 5.7ms；事件接收至模拟后Canvas提交p95分别为10.9ms / 10.6ms，最大分别58.3ms / 67.0ms。R/Q各5次的定点采样，同时观察对应动作状态和作用区域像素改变；数字见 `browser-scenes.json.feedback`。这是浏览器提交缓冲区的可观察反馈，不包括外设、显示扫描或人的反应时间，也不是所有电脑的帧率承诺。

实际游戏尺寸下按小批检查了三个Boss、两类符术、法天象地和奖励界面。紫粉为敌方危险，青色为己方符术，金白为大招。`ultimate-demo.gif` 来自公开导入场景后的真实R/Q/空格操作；其初始满战意、成长和符术次数已在 `showcase-save.json` / `showcase.json` 披露。GIF只裁切、缩放、降帧和调色，原始视频保留；它是定点动效展示。

## 主观证据与缺口

开发侧动态审看认为Boss轮廓与两种招式可区分，金色大招、青色符术和敌方预告有层级区别。真人首次理解、手感、重复游玩意愿和真人试听尚未取得。动画仍以关键姿势与动态效果为主。

新守关者为游戏原创；本轮未新增可观看原剧片段核查。法天象地借用西游神通名，其动作与数值为本游戏设计，不宣称复刻原剧镜头。PC Edge已实际检查；其他浏览器、移动端和辅助技术的完整覆盖不在本次验收结论中。

真人试玩流程已准备：找3–5名PC动作游戏玩家，首次只给按键，不讲Boss解法；记录发现战意条、首次释放R、第一次符术、看预告后的移动及受伤后调整；再询问看到了什么、为何受伤、下一次如何做。交替安排招式优先/神通优先的选择顺序，单独记录口头评价、实际选择和自愿重开。这些小样本用于发现问题。

## 运行与复核

构建不需要npm依赖。高级检查需要Playwright与Edge；本机设置捆绑运行时的 `NODE_PATH`。旧版本工具记录保留，当前命令如下：

```powershell
npm run build
npm run verify
node tools/serve.cjs
node tools/playthrough-v4.cjs http
$env:EVIDENCE_DIR='evidence/progression-v4'
node tools/dialog-ui-verify.cjs http
# 停止5188预览后：
$env:REQUIRE_SERVER_OFF='1'
$env:BUILD='mystic'
$env:JUMP_KEY='Space'
node tools/playthrough-v4.cjs file
node tools/dialog-ui-verify.cjs file
node tools/progression-v4-browser.cjs
```
