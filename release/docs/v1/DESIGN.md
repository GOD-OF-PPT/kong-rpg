## 体验与选择

体验句：以能沉住气破局的孙悟空，借跳跃与棍法争取空间，把挣来的定力用在真正值得的分身窗口上。

方向 A：纯跑跳随机障碍，节奏直接但神通易沦为跳跃皮肤。方向 B：跑跳穿越 + 小型破阵战 + 舍利改变战斗循环；保留超级玛丽式清楚的左右推进、短跳/长跳、踩敌与上下路线。选 B，避免把平台动作做成关门刷怪竞技场。

一局三段不同色光的山道/寺桥/灵山外庭，随后无天终局。每段破除两处黑莲阵眼后进入出口，路上敌人可战可绕。阵眼不可远距离无脑消除，周围敌人构成时机压力。每过一段选择一枚舍利，完成一局；死亡清空局内进度，只记局数、胜场和最远处，不提供永久数值碾压。相同种子复现布局、敌人和奖励，随机改变平台/敌型与奖励组合，不改变物理和招式规则。

实跑后收紧：古渡的第一处阵眼在高台，需要跳跃接近；残庭改变断桥位置。S＋空格下穿单向悬台，坠落回到带边缘余量的实地。无天护体期间免伤，收招金色环绕时可伤，收招后在两处位置之间转移。该调整来自“持续连按收益过高”的观察，没有扩充武器或敌种。

棍法：短前摇，三连末击较重、后摇更长；命中积攒定力，盾正面格挡。跳跃：100ms 土狼时间、120ms 输入缓冲、松键短跳；下落踩敌反弹；空中下+攻击下劈。闪避：短暂无敌且有冷却，提前交掉会暴露在下一次攻击。分身：40定力，驻留诱敌并攻击，施放后本体可以绕背；无法用分身跳过所有敌人。舍利以动作规则变化为主，不采用装备海。

敌人：执刃魔兵接近后亮刀再斩；重盾兵正面格挡、转向较慢、背面/踩踏/下劈可破；莲灯使远处发弹，逼跳跃或闪避。无天在地面横扫、散射和易伤喘息间循环，半血升级节奏；预警与命中时段分离。

## 在验证前冻结的假设与标准

H1：跳跃/绕背可有效破解盾正面。固定局面比较正面连续攻击与绕背/下劈；前者必须被挡，后者必须造成伤害。若任一招能无代价解决所有局面，修改规则。

H2：分身流与腾云流改变操作。相同种子与敌局比较：分身持续时间/攻击方式确实改变、腾云提供一次独立空中跳并改变到达平台能力；用行为及资源记录验证，不只看面板。真人是否认为两者同样有趣仍待外部试玩。

H3：键鼠操作清楚可响应。目标环境桌面 Chromium，事件到下一次画面提交 p95 <50ms；报告该指标不包含显示器扫描/设备硬件延迟。帧间隔 p95 <25ms（注明自动化环境，不泛化硬件）。暂停/奖励/失焦时无战斗输入泄漏。

H4：离线包独立。全新会话阻断所有 HTTP(S)，直接打开 HTML 能开始、战斗、奖励、终局/失败、重开；HTTP 同版本流程亦验证。自动存储失败不会阻塞启动，JSON 导出导入能恢复状态，拒绝损坏或不支持版本的存档。

## 美术执行

960×540 固定逻辑画布，整数坐标绘制，角色以2像素为最小笔触；缩放保持 nearest-neighbor。原创程序像素图块/精灵在本地生成并缓存，避免不统一的生成贴图。

主色：墨紫 #171426 / 山青 #223e48 / 石灰 #4b5560 / 旧金 #e7ba70 / 朱红 #d35450 / 云白 #eee0be；危险紫红 #d66bba，友方分身青 #76d7cf。悟空金冠、橙金毛发、红围巾、深靛裙甲和两端金箍的长棍；魔兵窄长紫甲，盾兵宽轮廓，莲灯使悬空绿焰，避免只用换色区分。

远景低对比重叠山峦、月轮、断塔剪影；中景云带与飞檐；近景石桥边缘、裂纹、青苔、经幡和灯笼。落脚面用连续浅金边，非碰撞远景不使用同样亮度。脚底影子明确落点。攻击弧在有效帧变亮、命中以短闪/碎屑/45ms停顿表达；伤害有来源文字，屏震可关。文字全部 DOM、系统本地中文字体，不下载字体；主标题用宋体形成古碑感，正文为清楚的系统黑体。

常驻 HUD 只放生命、定力、当前段目标与暂停；构筑和控制摘要置底边，完整说明在暂停/图鉴。菜单和奖励暂停模拟，按钮可键盘导航，1/2/3 选择奖励。
