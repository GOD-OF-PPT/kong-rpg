# 敌人战纹 · v8.0.1

范围：只重做敌人头顶信息的图案和合成；保持 schema8、攻击判定、技能时序与掉落规则。

起点：分支 `codex/three-heroes-realms-v8`，HEAD `133fad8e280a0cbb5fd4a566a1a94fec3d0206e4`，工作树干净。独立分支 `codex/enemy-marker-art-v8`。

## 原始问题与修正

用户两张截图中的空方框和双短竖线，来自 `journey-art.js` 的震盾、连刃特性图案；方块感叹号来自基础 renderer。挑战冠标和破距盾标另在其他绘制层叠加。旧特性在平台绘制前出现，还可能被上层平台遮住，留下感叹号却丢失身份。

现在仅由 `enemy-marker-art.js` 在世界绘制后统一合成一枚战纹。常态24像素，起手外圈34像素；素材只在首次使用时按实际尺寸以最近邻采样并缓存，避免每帧缩放与平滑模糊。暗墨轮廓、古铜底、象牙色主体与朱红刃芒共同形成像素视觉语言。

| 图案 | 意义 | 状态关系 |
|---|---|---|
| 交错双刃 | 连刃 | 第二斩重新亮起危险外圈 |
| 带翼震盾 | 震盾 | 盾撞后低位震波，原地面提示保留 |
| 三簇火焰 | 散焰 | 扇形三焰，原弹道提示保留 |
| 妖冠 | 挑战强化的无特性敌人 | 有特性敌人融入朱红轮廓，不再叠冠 |
| 向下锋刃 | 无特性敌人起手 | 收招后消失 |
| 四角朱红刃芒 | 正在蓄力 | 包住原身份图案；不伪造冷却计时或命中保证 |

不靠颜色独立传递含义。常态纹样与危险尖角轮廓不同；不是绿色补给或可拾取物。战纹与血条分层，以碰撞体顶边向上43像素统一定位，并检查大体型守关者/无天的头部间距。相邻徽记优先保持攻击预警，再短距离错位避让；画面边缘限制在可见区域。死亡、休眠与当前硬直时不显示主动起手预警。`realm-echo` 是原有第二段蓄力，名称没有 windup，现纳入相同提示。地面/弹道预警仍是实际危险位置依据。

## 素材来源

使用内置 ImageGen，生成一张六格 atlas，再通过 ImageGen 去除装饰细节、简化像素块。没有用代码手绘符号替代生成素材。选用第二版 RGBA 原图，完整复制到 `assets/enemy-markers/battle-seals.png`，不改写其 alpha。运行时仅切片、最近邻取样和为挑战状态增加贴合图案轮廓；不是额外的头顶图层。

原始文件名、SHA256、两轮完整提示词见同目录 `PROMPTS.md`。图片审阅每批1–2张。第一版未采用，保留在生成目录，不计入发行资源。

## 预先约定的检查

1. 三种特性在实际24像素取样后非空，危险外圈中心透明，六个格子不越界、无解码失败。
2. 相同固定种子 `MARKERS-1027`，导入真实 schema8 场景，对比特性常态、蓄力、血条、二连斩、挑战、守关者、无天与地府二次锁定。检查旧符号消失、图案不被平台遮盖、血条可读、外围不盖住主体。
3. 受控拥挤/低顶/画面两端布局不重叠、不裁出画布。此项只证明这些局面，不能外推到任意敌群密度。
4. 通过真实键鼠与DOM检查攻击、暂停的输入隔离、导出导入和恢复。正式打包后停止预览，在全新断网浏览器中打开解压入口，确认零HTTP请求。

通过标准是资源/状态对应与上述实际画面均可复核；首次玩家是否不用解释就认得三种特性仍需真人试玩，不用自动化代替。
