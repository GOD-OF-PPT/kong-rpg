# v5：长路有取舍

基线：v4.0.0，`b053da94f58f6e531186cc5efcc62fb035790aef`；开发分支 `codex/journey-depth-v5`。保留 Canvas2D、classic scripts、960×540 和原创素材。本轮不改角色、大招、独立守关者与胜负规则。

## 调研与取舍（2026-10-26）

联网搜索工具返回 HTTP 403，改为直接读取开发者官方更新记录；未声称亲自玩过参考游戏。原始页面摘录保存在 research/。

- [Dead Cells Update 19](https://deadcells.com/patchnotes/19)：开发者将装备等级、经济和敌伤一起调整，以提供途中换装备的机会与动机；并修正食物生成在可能关闭的门后。推论：长路必须有可取得的资源，不能只延长消耗。本项目采用确定性的杀敌掉落与一次休整，掉落落在可站立表面、不隔门。
- [Dead Cells Update 26](https://deadcells.com/patchnotes/26)：初始区域中的异常房间让探索带来新工具。推论：支路需要改变后续打法的回报。本项目每境设置可跳过的试炼，奖励复用已有舍利、法门、符术，不另造装备系统。
- [Dead Cells Update 23](https://deadcells.com/patchnotes/23)：开发者撤除疫病造成的敌人移速提升，并清理误导动画。推论：难度应来自可读行为而非压缩反应时间。本项目三种强化分别增加二段斩、低位盾波、扇形莲焰；保持基础血量，额外招式预警可打断、跃过或返弹。

这些是版本记录及本项目推论，不是关于参考游戏整体设计的统计结论。新试炼、补给与招式为游戏原创，无新增原剧场景研究或剧情事实主张。

## 实施方案

1. HUD 常驻已携舍利及法门；B/按钮打开暂停式「本局法门」，逐项显示效果、等级、代价、符术余量与基础能力。奖励时也可查看，再返回原选择。
2. 三境由5160延长到7320（+41.9%），插入2160长度的实质路线；每段含上下两路、组合敌阵、可选试炼和一次休整。原事件和原守关者保留，竞技场坐标数据化。
3. 终局由960延长到3480；前置2520长度的双阵与混合遭遇，破阵后进入原尺寸无天战场。无天招式几何随竞技场平移，不扩大招式范围。
4. 三类强化怪不加血：连刃有第二段预警；震盾留下低位可返弹棍波；莲灯扇射有更长蓄力。形状徽记、预警与实际碰撞共用几何。
5. 杀敌按种子和敌人ID确定掉落：小药12生命、灵光20定力、战意14。强化怪必掉，普通怪部分掉。不刷新、不计时消失；资源满时留在地上。试炼额外奖励与休整均一次性，保存状态。

## 在验证前确定的通过条件

- 已选项在HUD可辨认，详情中每项效果与模拟一致；B/Esc/Tab与鼠标切换不漏输入，打开详情不推进世界。
- 同种子同敌掉落一致；受伤恢复、满资源不浪费、拾取不重复；试炼可略过、奖励仅一次；存档恢复所有新状态并拒绝伪造。
- 三境与终局长度实际增加，新增段含战斗和上下路线；无腾云也能过全部强制断口。不同种子不造成断路。
- 相同局面持续轻棍与观察二段预警后闪避/重棍的结果可区分；不强迫使用单一技能；至少两套已有构筑可用。
- 正式发行包在HTTP与全新断网file会话中完成真实键鼠完整胜负流程；检查帧间隔、输入到提交、保存恢复、无网络和异常。自动化行为不代表真人喜欢。
- 以1366×768和1440×1000实际画面检查HUD、构筑卷轴、掉落、精英预警；不只检查DOM。

无人类试玩者可调用；保留3–5名PC玩家首局观察流程：不解释招式，交替构筑顺序，记录二段斩受伤归因、试炼选择、资源回头拾取及自愿重开。此项不由脚本替代。
