# 三兵与诸界 · v8 制作目标

基线0fa74cb（v7.1.3），分支codex/three-heroes-realms-v8。目标：三位角色在同一套读招和平台规则下，靠主副武器、资源与站位选择破局；五种新领域同时有场景、地表、怪物和可理解的敌招。

## 选择与验收门槛

- 哪吒J/左键火尖枪三连，H/右键掷乾坤圈。一环在外可继续近战，去回命中分别去重；L混天绫和U风火轮保留。圈耗12定力，不能无限远程连发。
- 杨戬J/左键三尖两刃刀，H/右键射雕弓：箭有准备、消耗18定力和冷却；L天眼识破消耗30定力，使短期目标露出破绽；R召唤哮天犬持续8秒协战，犬追击、起跳扑咬并有攻击间隔，离开战场或死亡后收回。U短冲步法不提供飞行。
- 悟空原三连、分身、如意伸棍和法天象地继续可选。所有主副武器在DOM菜单均受输入隔离，按键与鼠标提示一致。
- 五种领域接入现有四境的连续路段：山道后段→云上→天宫；古渡后段→水下→龙宫；残庭后段→地府。沿用既有长度及终局，领域有固定边界和各自的怪物外观/招式；不把背景换色当作新作战内容。
- 每领域两种怪物主体，使用已有刀/盾/法师碰撞与普通招式骨架，另增加预警锁定的领域技能。预警后不跟踪，重击可打断，至少有正常移动或跳跃的规避法。
- 敌人轮廓暗红、攻击预警玫红；增益底标青绿并有葫芦/珠/焰形状；已满资源和已使用物件不假装可拾取。友方犬青金标，色彩之外依赖轮廓/底标/名称。避免全身常亮粗红边遮盖动作。
- v7原发行HTML保留为legacy-v7，schema8及独立存档键保护旧旅程。副武器、箭、天眼、犬和领域技能中间态可实际导出恢复。
- ImageGen产物须入场、真实透明、共同比例/脚底锚点，无遗漏状态。HTTP及关闭服务后断网file正式入口验收，保留种子、输入、截图/短片和哈希；真人体验评价单列未验证。

新领域、敌招、资源成本和杨戬能力均为本游戏原创实现，采用用户指定武器设定，不宣称复刻《西游记后传》某一场原片。
