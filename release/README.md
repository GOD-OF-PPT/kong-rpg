# 大圣·劫后行 v2 — 游玩说明

解压离线包后双击 `index.html`。推荐桌面 Edge / Chrome。无需服务端、网络、安装或修改浏览器设置。声音需第一次点击后启用，可在暂停中调低或静音。

## 开始与目标

开篇后选择腾云骨、照影珠或定海心起步。走过雾隐山道、悬灯古渡与灵山残庭；每境打碎两座紫色黑莲阵眼，到最右山门按 E。完成三境后迎战无天，随后有胜利结算与原创尾声。

这是一款紧凑的完整小体量游戏，不提供永久属性碾压。自动操作的通关时间不能当作普通玩家的游玩时长；第一次可以多看落点和敌招，回身探索上层补给。

## 操作

|操作|键鼠|
|---|---|
|行走|A / D 或左右方向键|
|跳跃|空格 / W / 上；长按高跳，松开短跳|
|下穿悬台|S + 空格，不会穿过实地|
|棍法三连|J / 鼠标左键；按住可连击，鼠标指向决定出棍方向|
|下劈|空中 S + J；业火莲扩大落地火环|
|闪避|K / Shift；短暂无敌，0.85秒冷却|
|分身|L / 右键，40定力；照影珠50定力|
|借灯 / 过门|靠近对应位置按 E|
|暂停 / 返回|Esc|
|选择舍利|点击卡片或1 / 2 / 3|

踩敌可以反弹。腾云骨再给一次空中跳；脚下浅色亮边是能站立的地方。云渊和暗河不能落脚，坠落扣18生命并回到近处实地。

## 观察与选择

金色举刀是蓄力，红色刀光才是伤害阶段。连续轻棍不会冻结敌招；重棍和踩踏可以打断普通敌人蓄力。普通盾兵可以绕背、等收招或借定海心第三棍破盾，不必硬撞正面。

莲灯使会以虚线标出锁定的瞄准方向，离开那条线或用回锋印迎弹闪避。阵眼也会先亮起预告，再向两侧放出莲焰。

无天的黑莲只护在面朝方向：正面仍可造成部分伤害，绕背与金色收招阶段可以完整输出。横扫低位，跳跃可避；移形冲击前地面有路线预告，提前离开或跃起。没有全身免伤等待。

## 三枚舍利与借灯

最多携带三枚。每境第一处阵眼打破后，靠近按 E 可整顿；选择后回到原处，可继续探索。山门过境时也有一次选择。

新舍利会要求你明确放下一枚，不会默默丢装备。也可选「借灯调息」恢复30生命、35定力，保留原构筑，但放弃这次换法的机会。过境另恢复18生命与20定力。

## 存档与设置

每3秒及暂停、选择、结算时自动保存；音量与屏震设置亦保存。关闭或重开浏览器后，从「继续旅程」返回。导入的战斗旅程会暂停，等待你继续；选择中断时，也会保留待替换的舍利。

HTTP 与双击入口的自动存储相互独立。请通过暂停菜单导出 JSON 带走进度；自动存储被浏览器禁用时，游戏仍可玩，但务必手动导出。

v1存档不会被覆盖或强行移到新地图。新版的「原版旅程」入口会先备份旧档，再打开保留的 `legacy-v1.html`；在原版的初行指南中导入旧JSON继续。

## 来源和边界

动作、地图和尾声为游戏原创；未取得可核验的原剧逐帧片段，不能视为影视动作复刻。程序像素图和WebAudio均在本地生成，运行不使用CDN、远程字体或在线接口。

已进行的功能、行为和发行验证见 `docs/v2/VERIFICATION.md`；真人体验仍需按 `docs/v2/PLAYTEST.md` 观察，不以自动化冒充真人评价。
