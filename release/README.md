## 直接运行

双击 `release/index.html`；或解压 `artifacts/kong-rpg-offline-v12.2.0.zip` 后双击包内 `index.html`。PC Edge / Chrome，无需网络、安装、CDN、字体下载或安全设置。保留同目录 `legacy-v1.html` 至 `legacy-v11.html`，供旧旅程继续。

源码预览需要Node.js 18+，不需npm install：

```powershell
npm run build
npm run dev
```

本地入口：`http://127.0.0.1:5188/release/index.html`。局域网执行 `npm run dev:lan`，同网络访问 `http://本机IPv4:5188/`；LAN模式只提供发行目录。

## PC操作

|输入|孙悟空|哪吒|杨戬|
|---|---|---|---|
|J / 左键|金箍棒三连|火尖枪三连|三尖两刃刀三连|
|H / 右键|破空棍劲，22定力|乾坤圈，12定力|射雕弓，18定力、0.22秒准备|
|L|分身|混天绫|天眼识破，30定力|
|U|按住蓄伸，松开刺；S松开撑跃|按住驭轮，W/空格升、S降|神行步，12定力|
|C|撑天坠击 / 回身棍阵|三头六臂|三目神光|
|R|法天象地|莲火轮阵＋4秒附枪|哮天逐邪，召犬协战8秒|

右键朝光标发棍劲/投环/射箭，H水平出手。A/D或方向键移动；空格/W跳跃，长按高跳、松开短跳；S＋空格下穿；空中S＋J下劈。K/Shift闪避，Q使用携带符术，F交互/借灯/过门，B查看全部本局加成，Esc暂停。菜单可用鼠标、Tab/Enter，选人和奖励支持A/D、方向键与1/2/3。

一次只有一枚乾坤圈在外，去回各命中一次。射雕箭有成本与冷却，正面盾可挡，破军锋或天眼提供破盾解法。哮天犬自行追击附近活跃目标，有扑咬间隔和持续时间，需要玩家牵制；它不会替代玩家的移动与读招。

六枚舍利最多携带三枚；法门不占舍利槽；符术限次。奖励按角色解释，能改变空中打法、破盾、回程、神通结束位置或大招持续。失败清空本局成长，可同种子重开，不提供永久战力。
