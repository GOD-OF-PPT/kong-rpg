# 大圣 · 劫后行 — 独立离线版

双击同目录的 index.html 即可游玩，推荐 Windows 桌面 Edge / Chrome。无需安装、服务端或网络。

A / D 移动；空格跳跃，松开短跳；S + 空格下穿悬台；J / 左键棍击；空中 S + J 下劈；K / Shift 闪避；L / 右键分身；E 过山门；Esc 暂停。

每境破两处阵眼再到右侧山门按 E。三境之后挑战无天：护体时无法受伤，金色收招阶段出棍。

首次可选腾云骨，允许二段跳。定力不足时用棍击命中来积攒。暂停菜单有完整手记、音量、屏震开关与存档导入导出。

浏览器禁止自动存储时仍可玩；请主动导出 JSON，另次通过导入继续。

玩法与美术依据、调研限制和验证记录在 docs 目录。源码仓库：https://github.com/GOD-OF-PPT/kong-rpg/tree/codex/black-lotus-pilgrimage
