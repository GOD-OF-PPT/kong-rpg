# 大圣 · 劫后行 v10.0.0

五界归途：孙悟空、哪吒、杨戬可选的像素横版平台动作肉鸽。依次走过五章十五关，击退十名小首领与五名大首领，最终迎战托塔天王。玩法、角色和美术均基于用户设定创作，不宣称复刻电视剧中的具体战斗。

## 本版更新

- 五章十五关，严格依次为云上、地府、水下、龙宫、天宫，每章三张独立布局。
- 每章前两关小怪与独立小Boss，第三关迎战大Boss：巨灵神、秦广王、九头虫、东海龙王、托塔天王。共10名小Boss、5名大Boss，15种普通怪外观/职责按关卡组合。
- 秦广王判牒护体可破、龙王潮珠可打断、天王塔基可摧毁；巨灵神重斧与九头虫毒潮分别考验读向、跳避与弹间空隙。前两关逐步教授这些判断。
- S/A/B/C综合评级：时间35分（25分钟内满分，其后每分钟扣2分）、实际受伤次数40分（每次扣0.5分）、唯一计分敌人击杀率25分。S≥90、A≥75、B≥55，其他C。
- 挑战仅在普通完整十五关通关S评级后开放（严格高于A）；每关多3名敌人，大首领有二次锁定与追击预警，不靠统一增加血量。普通110个计分敌人、挑战155个；塔兵召唤不刷分。
- 保留三英雄、主副武器、四项秘技、舍利/法门/符术，F拾卷、C秘技、B换技。新增50条像素切片，完整离线内嵌。

目标、机制与边界：[GOAL](docs/campaign-v10/GOAL.md)、[DESIGN](docs/campaign-v10/DESIGN.md)、[VERIFICATION](docs/campaign-v10/VERIFICATION.md)。

## 直接运行

双击 `release/index.html`；或解压 `artifacts/kong-rpg-offline-v10.0.0.zip` 后双击包内 `index.html`。PC Edge / Chrome，无需网络、安装、CDN、字体下载或安全设置。保留同目录 `legacy-v1.html` 至 `legacy-v9.html`，供旧旅程继续。

源码预览需要Node.js 18+，不需npm install：

```powershell
npm run build
npm run dev
```

本地入口：`http://127.0.0.1:5188/release/index.html`。局域网执行 `npm run dev:lan`，同网络访问 `http://本机IPv4:5188/`；LAN模式只提供发行目录。

## PC操作

|输入|孙悟空|哪吒|杨戬|
|---|---|---|---|
|J / 左键|金箍棒三连|火尖枪三连|三尖两刃刀三连|
|H / 右键|分身（同L）|乾坤圈，12定力|射雕弓，18定力、0.22秒准备|
|L|分身|混天绫|天眼识破，30定力|
|U|按住蓄伸，松开刺；S松开撑跃|按住驭轮，W/空格升、S降|神行步，12定力|
|C|撑天坠击 / 回身棍阵|三头六臂|三目神光|
|R|法天象地|莲火轮阵|哮天逐邪，召犬协战8秒|

右键朝光标投环/射箭，H水平出手。A/D或方向键移动；空格/W跳跃，长按高跳、松开短跳；S＋空格下穿；空中S＋J下劈。K/Shift闪避，Q使用携带符术，F交互/借灯/过门，B查看全部本局加成，Esc暂停。菜单可用鼠标、Tab/Enter，选人和奖励支持A/D、方向键与1/2/3。

一次只有一枚乾坤圈在外，去回各命中一次。射雕箭有成本与冷却，正面盾可挡，破军锋或天眼提供破盾解法。哮天犬自行追击附近活跃目标，有扑咬间隔和持续时间，需要玩家牵制；它不会替代玩家的移动与读招。

六枚舍利最多携带三枚；法门不占舍利槽；符术限次。奖励按角色解释，能改变空中打法、破盾、回程、神通结束位置或大招持续。失败清空本局成长，可同种子重开，不提供永久战力。

## 保存与旧版

v10使用schema10和独立键 `kong.black-lotus.v10`。每3秒及暂停/结算等时机自动保存；导出/导入可以恢复秘技装备/共享冷却/施展中间态、参悟选择、副武器、引弦、箭、天眼、哮天犬和敌招中间态。自动存储不可用时，用JSON导出保存进度。

v9.0.0原HTML保留为 `legacy-v9.html`，旧v9存档走原规则入口，不会静默赋予新技能或改写旅程。更早版本入口也保留。HTTP与file自动存储按浏览器来源分开，可用JSON导出导入迁移同版本旅程。

## 美术、音乐与验证

新增源图、归一图集与SHA记录在 `assets/campaign-v10/`，完整提示词在 `docs/campaign-v10/PROMPTS.md`。`tools/prepare-campaign-art.py`仅进行明确裁切、共同比例、nearest-neighbour归一，保留真实RGBA。53张内嵌图、271条切片在打包时检查；关键姿态不等于完整手绘逐帧动画。

背景音乐来自用户提供的 `assets/music/` 三首MP3：首次点击/按键后首页随机轮换，战斗单曲循环，切换淡变；原打击/预警音效继续使用。音乐和图像均内嵌发行HTML。

`npm run verify`运行当前v10规则检查；`tools/browser-campaign.cjs http|file`为本版受控场景与实际键鼠验收。`tools/playthrough-campaign.cjs http|file`通过公开输入完成十五关。旧版历史证据不计作本版新通关。QA脚本需要Playwright，游戏发行包不需要。未取得真人试玩，不把自动操作或图片检查等同于主观乐趣认可。

全量ZIP包含历史入口，超过GitHub单文件100MiB限制，作为本地交付物保留。重打包：`python tools/package-release.py`。
