# Boss 技能美术

通过内置 `image_gen` 生成，再做透明裁切和尺寸归一。生成提示词与迭代记录在 `PROMPTS.json`；原图、归一矩形及 SHA 在 `manifest.json`。运行只加载 `atlas.png`（768×1600，15 个部件），不加载设计草稿。

| Boss | 图集部件 |
| --- | --- |
| 巨灵神 | 斧风、带连续岩根的石刺、砂尘波 |
| 秦广王 | 朱砂判印、下垂魂链、幽冥墨烟 |
| 九头虫 | 毒液弹、毒浪、毒雾 |
| 东海龙王 | 雷云、清晰白热雷电、水柱 |
| 托塔天王 | 七宝塔投影、金色光缎、火轮 |

石刺使用 `grounded-spires.png`，不是悬浮碎石爆炸图；雷电使用 `lightning-sharp.png`。根部埋入地形 24 个世界像素，先于平台和角色绘制；大面积烟、水、光效也先于人物绘制，接触火花独立位于前景。透明 alpha 原样保留，不作底色抠图或手绘背景修补。

运行效果采用清晰采样与普通 alpha 合成，不使用模糊滤镜、矩形色幕和边界线。`node tools/prepare-boss-fx.cjs` 可重建图集和 `src/boss-fx-data.js`。
