# 背景音乐 · v7.1.3

三个用户提供的MP3已接入，文件名固定为：

- `menu-01.mp3`：首页背景音乐之一。
- `menu-02.mp3`：首页背景音乐之二。
- `gameplay.mp3`：游戏中背景音乐。

首页首次点击或按键后随机起播，两曲轮换且避免连续重复；游戏中单曲循环。进入游戏/回首页约0.65秒淡入淡出；暂停和阅读奖励降低音乐音量。隐藏页面暂停，重新可见时恢复。死亡、通关、尾声淡出，保留结算和音效空间。

原MP3字节保持不变。`manifest.json`记录源SHA、时长和播放增益；`tools/pack-music.cjs`校验后内嵌到发行HTML。替换音乐后需重新核对并更新源SHA，不能悄悄使用同名不同文件。

`src/music.js`负责播放/轮换/循环/淡变，`audio.js`接入既有总音量和音效总线，`app.js`传入界面状态。没有运行时HTTP音频加载。验收见`docs/music-v7/VERIFICATION.md`。
