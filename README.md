# 大圣 · 劫后行 v4.0

本版加入 R「法天象地」、五种局内根骨/招式强化、两种 Q 限次符术，以及三境独立守关 Boss。保留现有平台路线、三槽舍利、见闻事件与最终无天战。制作依据、原创素材提示词和验收记录见 [docs/progression-v4](docs/progression-v4/DESIGN.md)。

v3.0.2 支持 A / D 或左右方向键选取舍利，适用于启程、奖励和替换界面；Enter 确认，1 / 2 / 3 速选。

v3.0.1 修正舍利卷轴文案挤压边框：完整说明、代价与确认文字各留出阅读空间，覆盖启程、奖励与替换界面。

当前版本强化棍法与命中动效，并为三境加入救困、渡灯接桥、镇莲钟事件，配合裂台、渡船、地焰和敌人新招。交互键已改为 F。设计、ImageGen提示词与验收见 [docs/combat-v3](docs/combat-v3/DESIGN.md)。

以《西游记后传》孙悟空为主角的像素横版动作肉鸽。看落点、识敌招，以棍法挣来定力，用分身和三枚舍利选择自己的解法。

## 游玩

直接双击 `release/index.html`。PC Edge / Chrome，无须安装、网络或浏览器设置。离线包解压后双击包内 `index.html`，请保留旁边的 `legacy-v1.html`、`legacy-v2.html` 和 `legacy-v3.html`，供旧旅程继续。

- A / D 或方向键行走；空格 / W 跳跃，长按高跳、松开短跳。
- S + 空格下穿悬台；J / 左键棍法三连；空中 S + J 下劈。
- K / Shift 闪避；L / 右键分身；F 借灯整顿或过山门；Esc 暂停。
- 棍击、破阵与反击积攒战意，满100按 R「法天象地」；Q 使用携带的雷符或护符，次数用尽消失。
- 舍利可用 A / D 或 ← / → 左右选取，Enter 确认，1 / 2 / 3 速选；菜单也可用鼠标、Tab / Enter。战斗中 Tab 先暂停再进入界面。

首次启程有开篇和分段提示。走过雾隐山道、悬灯古渡、灵山残庭；每境打碎两处黑莲阵眼，并击退山门守关者，经右端山门前往下一境，最后迎战无天。失败可同种子重开，胜利后有结算和尾声。

## 选择如何改变打法

轻棍无法冻结敌人的举刀。跳避、重棍打断或分身诱敌各有时机。重盾兵可绕背、等收招或用定海心第三棍破盾。无天正面的黑莲减伤，绕背与收招能完整输出；横扫和移形有提前可见的预警。

六枚舍利最多同时带三枚。每境首座阵眼破除后可按 F 借灯，过境也有一次选择。满位必须明确替换；选择调息则补充生命和定力，放弃本次换法。随机种子改变少量布置、敌人组合和奖励，跳跃和战斗规则保持稳定。不提供永久战力加成。

奖励还可选择金刚筋增加本局生命上限、破阵棍风让第三棍远袭、回身诀鼓励闪避穿身、散影诀要求安排分身结束位置，或如意余威延长大招的输出窗口。这些法门不占舍利槽。三霄雷符提供3次延迟落雷，金刚护符提供2次短暂护体；新符替换旧符。每次只能取一项，失败清空局内成长。

镇山魈王以冲撞与震地逼你判断跳跃时机；渡厄灯魁以散焰与索灯考察弹道和站位；缄愿法使以高光柱和低钟浪要求选择横移或跃起。紫粉标记为敌招，青色为己方符术，金白为法天象地。

## 保存

每3秒、暂停、整顿和结算时自动保存。导入/导出在暂停与手记中；导入的战斗先暂停，等待继续。音量和屏震设置保留。

HTTP 与 file 入口的自动存储独立。自动存储被禁用时仍可游玩，请用导出 JSON 保存，通过导入实际恢复。v1 / v2 / v3 的进行中旅程保留在对应旧入口。v4使用独立存档键和schema4，战意、法门、符术次数与Boss招式均随旅程保存。

## 源码与运行

Node.js 18+，无须 npm install，无运行时第三方依赖。

```powershell
npm run build
npm run dev
```

预览 http://127.0.0.1:5188/release/index.html 。`build` 从 assets 中的 PNG 重建内嵌素材脚本，再将脚本、CSS与图片全部内联到发行 HTML。克隆源码后先 build；正式发行包可直接离线打开。

`src/content.js` 内容与种子；`simulation.js` 固定120Hz模拟；`progression.js` 成长、符术、大招与守关规则；`input.js` 键鼠与焦点；`storage.js` 版本存档；`renderer.js` 世界渲染；`visuals.js` 与 `progression-art.js` 图集和动作；`app.js` DOM界面；`audio.js` 本地声音。

## 新版三境事件

山道：F破笼后击退守卒，救出的行者会解除本境地刺。渡口：F用20定力点亮灯枢，接回三处断桥，也可借移动渡船越过缺口。残庭：F叩响镇莲钟，击退守钟众后，无天落火由三处减为两处。事件都可略过；收束剧情会记住本局的取舍。

敌人新增突进斩、盾冲、锁地咒，无天增加先锁定地面的落火。看路径、离开莲印，或用重棍/踩踏打断普通敌人蓄力。

v4使用独立存档键与schema4，v1/v2/v3旧档保留在对应入口继续，不静默改变旧局规则。新版入口全部使用F；保留的历史入口按其原有按键运行。
