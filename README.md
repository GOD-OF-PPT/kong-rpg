# 大圣 · 劫后行 v4.0 · 法天象地

以《西游记后传》孙悟空为主角的独立离线像素横版动作肉鸽。随心易换「劈、立、戳」三棍势，施展「定身法、铜头铁臂、毫毛群猿」三大本命神通，碎雷火、淬金箍、破照妖古镜斩却心魔六耳，于黑莲法界迎战六臂灭世元神无天。

## 游玩与操作

直接双击 `release/index.html` 即可离线畅玩，无须安装任何依赖或联网。保留 `legacy-v1.html` 供早期版本旅程继续。

- **移动与立体机动**：`A / D` 或方向键行走；`空格 / W` 长按高跳、松开短跳；`S + 空格` 下穿悬台；踏上**金莲跃台**直跃高空秘径。
- **心猿三棍势与易势连携**：
  - `Q` 即时切换**劈棍势**（赤金裂地，绝技「断岳劈山」留灼烧金焰）、**立棍势**（青玉横扫，绝技「镇海雷罡」撑棍腾空避开地面杀招再轰落雷震）、**戳棍势**（攻距暴涨 40% 且可退寸进尺，绝技「贯日长虹」伸长 260 像素贯穿全线）。
  - 连招余韵中按 `Q` 可触发零消耗的 360° **易势闪击**！积满棍势按 `U / R`（或鼠标中键）倾注棍势释放当前流派绝技。
- **三大本命神通与毫巅识破**：
  - `F` **定身法**：凝金光「定」字锁住前方群敌与首领，连击叠满 3 次引爆**定印崩裂**重创。
  - `C` **铜头铁臂**：化金刚身弹反敌方挥砍、飞弹或洪流，瞬间震退破招并直得 **2 段棍势与 22 定力**。
  - `L / 右键` **身外身·毫毛群猿**：唤出多尊猴影自主追猎围攻；`K / Shift` 迎招闪身触发**毫巅识破**并激活突进破甲的**破妄追击**。
- **场景破坏、金箍淬炼与心魔对决**：
  - 击碎途中**雷火丹瓮**引发连环轰爆重创敌群，开启**灵蕴金匮**收集灵蕴磁吸光球。
  - `E` 在**淬棒神龛**消耗灵蕴重铸棒伤、缩减神通冷却或点化「真·舍利」；在**照妖心魔镜**迎战宿敌**六耳猕猴**，击败即可开启**第四枚本命舍利槽**与火眼暴击！
