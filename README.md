# 劫火重燃 v12.4.1

孙悟空、哪吒、杨戬可选的像素横版动作肉鸽。依次走过云上、地府、水下、龙宫、天宫五章十五关，击退守关首领，组合舍利、法门、符术和角色秘技。

## 游玩

离线版入口是 `dist-offline/index.html`，用 Edge / Chrome 打开。请保留整个 `dist-offline` 文件夹，包含图片、音乐和脚本；无需联网。

- A / D 或方向键：移动；空格：跳跃。
- J / 左键：主武器；H / 右键：副武器。
- K / Shift：闪避；L：角色神通；R：大招。
- U：角色变化；F：交互与拾卷；C：秘技；B：本局法门。
- Esc：暂停；菜单支持方向键、J / Enter 和鼠标。

普通模式完整通关并取得 S 评级后，可开启挑战。旅程自动保存，也可在暂停界面导出和导入 JSON 存档。HTTP 与本地文件入口的浏览器存储彼此独立。

## 开发与构建

Node.js `^20.19.0` 或 `>=22.12.0`。

```powershell
npm ci
npm run dev
npm run build:all
```

- `npm run build`：生成网络版 `dist/`，部署整个目录。
- `npm run build:offline`：生成离线版 `dist-offline/`，可直接打开或将整个目录打包分享。
- `npm run preview`：预览网络版构建结果。

开发预览地址为 `http://127.0.0.1:5173`，构建预览地址为 `http://127.0.0.1:4173`。

`src/` 保存游戏源码，`assets/` 保存实际使用的图像、音效、音乐及资源清单。资源校验、分段加载产物和离线脚本生成由 `vite.config.mjs` 完成。
