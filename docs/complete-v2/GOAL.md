# v2.0 制作目标

基线：c797b3dc154eb3f96d67725ca8de23d39df83a14（v1.2.0），工作区干净。开发分支 codex/complete-journey-v2。有选择地复用 968f6b7 中未完成的流程代码，保留当前 ImageGen 环境与角色资产。

体验：悟空靠看清落点与敌招、以棍挣来定力，再用变化打开进攻空当。

本轮完成紧凑的三境六阵→舍利取舍→无天终战→胜负结算与重开的完整游戏。三境数量、敌人种类与六枚舍利不增。玩法优先：三枚装备上限、借灯补给的机会成本、可绕背的无天护体。美术优先：六帧跑动、独立阵眼/灯/山门、判定一致的预警。

## 事先写下的验收标准

- 固定同一种子与资源，在近身举刀场景比较持续轻棍和看预警跳避；后者降低承伤。盾兵场景中腾云/照影分别产生空中位移/定力消耗与诱敌的可复现差异。若持续轻棍仍能冻结敌招，撤回结论。
- 无天在护体时仍有可做的事：正面削血、绕背全伤或整顿位置；移形前可见路线，攻击与渲染共享边界。移形瞬间伤害或无预警碰撞是失败。
- 实际键鼠从新开局连续完成所有三境、奖励、终战、结算和尾声；另外检查失败重开、满位替换、暂停、DOM焦点、动态存档恢复。
- 所有生成图在实际尺寸下检查脚锚、轮廓、预警与命中，不用概念图代替。保留录屏和当前包哈希。帧间隔 p95 <25ms，事件到渲染提交 p95 <50ms（不含硬件延迟）。
- HTTP 与服务器关闭后的新会话断网 file:// 都走完流程，file 零 HTTP(S) 请求；禁用存储仍可导出并恢复。v1.2 旧档不覆盖，保留原版继续入口。
- 不把脚本成功当成真人觉得好玩。没有外部试玩时保留这一项体验结论。

阶段按离线接入、玩法闭环、动作和辨识、发行验收持续推进。所有调整与边界记录到本目录。
