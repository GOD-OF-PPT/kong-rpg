# 首次真人试玩流程（尚未执行）

邀请3–5名习惯PC平台动作游戏的玩家，每人只给正常游戏内引导，不提前解释跳刀、绕背或构筑解法。录制完整画面和键鼠，取得录制同意。使用 LOTUS-1025，初始资源不变，先走第一境，再由玩家自愿继续；条件允许再检查终战迁移。

交替安排腾云/照影的先后顺序；比较版本时也交替顺序，避免练熟偏差。分别记录第一次举刀的注意和反应、伤害来源、空等时间、定力浪费、奖励选择、是否自愿重开。观察后才问“刚才看到了什么”“为何受伤”“下次准备怎么做”。保留原话与动作记录，二者分开。

失败条件：玩家反复被未识别的判定伤害；知道分身但找不到使用时机；只按住攻击与走动就无须改变策略；两套舍利在站位/路线/节奏上没有变化；重开只因为提示或被要求。先改对应规则/反馈再观察，不新增内容来掩盖。

这些样本只用于发现问题，不用于总体成功率结论。当前只有脚本操作、确定性模拟和画面检查，没有真人访谈、自愿重开证据或真人试听评价。
