# 挑战·黑莲重劫 — v7.1.0

目标：熟悉普通旅程的玩家，需要根据敌群分工、锁定位置和后续招式重新判断出手时机，才能稳定通关。保留四关、两角色、构筑与所有动作，不增加地图规模。敌人生命、伤害、玩家数值与奖励规则不加倍率。

本轮怪物新招为游戏原创，基于现有黑莲敌群设计，不宣称复刻原剧的具体招式。

## 规则

- 主菜单可直接选择普通旅程或挑战·黑莲重劫；选择仅影响新开局。HUD、暂停、结算和历史标识模式，死亡同缘重开保留模式。
- 前三境分别增加6、7、7名援兵；终局外道增加3名。只在真实地面与安全站位生成，避开坑沿、地刺和已有守卒，不在玩家身上刷怪。各援兵与原盾/刀/灯使组合，增加约五成常驻普通敌人。
- 刀兵：封路刀气，0.85秒锁线预警后发射，可跳避、绕位或用回锋返弹；近身重击可断起手。
- 盾兵：崩盾震，0.95秒后震击附近地面，打背不再是全程无风险的固定解；可跃过、移出或重击打断。
- 灯使：追迹双印，第一印0.95秒预警，释放时才重新锁第二印，第二次再给0.75秒。每次锁定后不追踪，分身仍可诱导。普通敌人最多两名同时蓄新特殊招式；普通招式保留自身时序，Boss按自己的连招进行。
- 山王冲撞后0.7秒回震；渡魁散焰后0.85秒对渡焰，可跳避/返弹；法使封愿后0.8秒余钟震；无天落火后0.8秒追落莲印。后续招式结束保留1.7秒收招。钟声见闻仍削减无天的追落标记，R仍可打断守关者。
- 新招式预警和真实伤害共用几何；新增印区沿用像素图集、边线和音效，二印多一枚角标。强化敌人有小型双齿冠纹，不以换色替代危险提示。

## 存档与稳定性

schema7保留，普通旧档缺少difficulty时按normal恢复，不加入援兵或新招式。新档记录difficulty和challengeRules=1；挑战房间按模式重建，保存冷却、锁定点、阶段和弹道来源。不允许读档改模式，不把普通进行中旅程升级成挑战。

## 先写下的验收条件

1. 相同种子/模式固定人数、出生点与掉落；普通地图和模拟与7.0.1基线一致。
2. 新技能须可被预警识别；锁定后移动不改变已有标记。至少一种正常移动/跳跃/返弹/重击方案可避开每招，原地持续攻击受更多压力。
3. 各Boss新连招在同一存档前后保持阶段与真实命中区，结束有完整收招，不无限续招。
4. 普通旧档、挑战新档、暂停、奖励、同缘重开、历史与胜负结算均可恢复，不能静默混用模式。
5. PC键鼠实机截图/录像检查；HTTP与关闭服务后的断网file入口运行，无外部资源。挑战完整流程用实际键鼠记录；控制器失败保留，不通过降低敌伤伪造成功。真人难度评价单列为未验证。
