## 截图确实发现并修正的问题

- 原素材是非等高排版，流水底部跨入下一行。按4×4等分会把水纹切入墨印、塔印、石裂、碎石，素材存在检查对此无效。采用明确源矩形重新切片并统一缩放，保存为materials-v2.png；原始源图和materials.png保留。本轮没有重新生成美术、没有用色块替代原画。
- 悟空大招的棍浪原以角色为中心，1162个可见像素画在真实方向伤害框外。改用伤害框中心并裁切后，框外像素为零；巨大法相主体保留。
- 哪吒首轮伤害即时覆盖600宽，首帧光环却仅约226宽。改为接近实际范围的起始环，首帧可见宽度约560，并在外围加入既有莲火接触节点；两轮释放分别采样，中心透明。
- 大招、护体、闪避共用受伤后的无敌闪烁，角色会在主动施法时变淡。主动保护动作保持人物不透明；真实受伤仍保留原闪烁。没有改变无敌时间、伤害或技能代价。

像素观察工具check-skill-visuals.cjs实际运行新旧效果层，旧层固定为9e7708d；检查可见像素范围、人物渲染alpha和异色污染，不用测试数量替代审美判断。源比较确认模拟、输入、存档和音频文件与基线相同；content.js仅版本号变化。本轮无玩法平衡变更。

## 观察方法与限制

Windows / Edge Chromium，Canvas960×540。通过公开JSON导入固定种子VISUAL-SKILLS-1028的规范靶场，再用真实键鼠启动技能。截图在最终Renderer绘制后，按实际起手、释放、命中、收回状态采样，保存当时坐标、事件、判定框和时间；没有为截图改伤害或在战斗中注入命中。静态靶场不等于自然通关。

所有46项已分小批逐项查看关键帧。秦广王复判包含首次受击后真实横移；分身包含本体离开驻影；哮天犬抓取实际扑咬命中，不以起跳姿势冒充打击。部分技能生效与命中处于同一帧，时间保留，未伪造多余动作。连续视频保留在各采样目录；未完整人工观看全部录像。

最初的before采样误用长收招作为静止靶，触发了首领撤步，另有盾波目标站在缺口导致漏采。baseline修正了这些靶场准备问题，184帧齐全；其中18项无影响的怪物画面明确标记复用同一入口的before记录。最终final为当前完整新采样186帧，入口哈希写在capture.json中。

仍有四项可优化：分身在蓝色背景偏淡；天眼范围的虚线矩形偏几何；巨灵神冲斧缺少连续接地脚步；九首俯冲压低姿态与较高危险上沿仍有认知距离。这些结论写进截图册，未称全部美术已经满意。需要真人首次辨认、密集挑战场景和主观质感评价；本轮没有外部真人样本。
