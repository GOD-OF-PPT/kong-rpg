# 劫火重燃

**踏破五界，此战再起。**

《劫火重燃》是一款神话题材的像素横版动作肉鸽游戏。化身孙悟空、哪吒或杨戬，穿越云上、地府、水下、龙宫与天宫，在五章十五关中迎战各具招式的守关者。读懂出招，抓住破绽；选择舍利、法门与秘技，打造属于这一局的战斗方式。

## 主题诠释

“劫火”象征封锁五界的危局，也代表每次交锋必须面对的考验；“重燃”则是战败后再次启程的意志。神通再强，也需要判断与取舍。记住一次受伤的原因，换一种接近敌人的方法，让下一次出手更有把握。

## 核心玩法

- **三位应劫者，三种战斗节奏。**悟空以棍法、伸缩与分身创造破绽；哪吒用火尖枪、乾坤圈与风火轮交织攻势；杨戬结合三尖刀、射雕弓、天眼与哮天犬安排距离。
- **跑跳与读招共同决定胜负。**跨越断桥、高台与危险地带，观察敌人的起手、攻击方向和收招，在闪避、绕背、反击与施展神通之间作出选择。
- **每局构筑，改变出手方式。**沿途取得随机奖励，选择舍利、能力强化、限次符术与角色秘技。让有限资源服务于自己的打法；失败后局内成长重置，再次选择新的破局路线。
- **五界十五关，逐层迎战首领。**每章两场小首领战与一场大首领战，面对斧势、锁魂、毒潮、水雷与塔阵，寻找各自的应对方法。
- **以表现解锁更高挑战。**通关按用时、受伤次数与计分击杀评定S/A/B/C。普通模式完整通关并获得S评价后，解锁敌阵更密、隐藏招式辅助指示的挑战模式。

PC键鼠操作，支持离线游玩。
