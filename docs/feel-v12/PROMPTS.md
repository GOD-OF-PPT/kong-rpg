# 动作图集生成与接入

使用内置ImageGen，以已发行的孙悟空以外两位英雄/五区军队造型为参考，输出均保存至assets/motion-v12。逐张或两张检查，没有一次载入大量图。完整8次生成/修改的实际提示词与工具调用源码存于IMAGEGEN-CALLS.json（含两次各2张的独立请求）；该文件不是运行时代码。

## 采用资源

- nezha-source.png：四列五行，跑步4帧、三连各4阶段、起跳/下落/受伤/站姿。红绫、金甲、青裤和火尖枪保持原造型。
- erlang-source.png：相同布局，三尖两刃刀的短切/上挑/重劈，白披风与蓝金甲保持原造型；重劈实际接触段采用既有actor-repair清晰帧，避免新姿势刀刃落到判定以外。
- cloud / underworld / water / dragon / heaven-source.png：各六列五行，现有三类普通敌人和两名小首领每种6姿势，行内同一身份/体态。列依次为两步行姿势、起手、释放、收招、受击。水下保持虾、蚌、鱼、龙虾与蛇形生物的各自肢体结构。
- cloud-source.png为定向编辑后的木弩，未采用第一稿容易误认成枪械的长直武器。

所有图集使用透明alpha，源图透明区域仍可能包含背景RGB，归一时以alpha分割连通角色，保留相邻抗锯齿边缘，预乘alpha Lanczos缩小。统一每位英雄/每行敌人的缩放，测量脚底锚点；不按每帧包围盒分别放大。完整190帧的源区域/锚点/缩放/SHA在normalization.json，产物由motion-data.js登记。

## 未采用

erlang-refined-draft.png的加长编辑造成两对相邻角色相连，20个角色的连通检查只剩18个完整区域，未接入；未为了留下生成图而接受裁断兵器。cloud-source-draft.png也是旧稿，不在素材包清单。发行只内嵌七张归一图，不加载源图或生成服务。

## 使用约束

动作帧不能自定义伤害时间：K.attackPhase及K.attackTiming同时决定起手/生效/跟随/收招。图像只表达同一状态。站姿、奔跑、受伤、H/L、U、R和秘技按优先级选择，避免用射箭姿势代替主武器或被特效遮住受伤。像素世界960×540，文字仍在DOM。
