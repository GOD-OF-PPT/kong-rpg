# Boss 大招与技能来源

2026-10-30：按本轮要求放大五个 Boss 的整套招式，去掉怪物与 Boss 的技能范围框、虚线、箭头和安全区框，使用原生透明美术与动作预兆表达准备和释放。

| Boss | 封场招式 | 来源与躲避 |
| --- | --- | --- |
| 巨灵神 | 踏云震 | 石刺从地形内顶出，留一条未破裂的地面带；也可利用足够高度越过 |
| 秦广王 | 缚魂锁道 | 魂链从上方垂落，留一条无魂链区域 |
| 九头虫 | 污潮横涌 | 毒潮沿地面翻涌，留一条无毒地面带 |
| 东海龙王 | 龙角雷诏 | 雷电从天空贯穿整个战斗区域，只有一条未蓄电的通道 |
| 托塔天王 | 七宝镇阵 | 宝塔投下金色光缎，留一条未镇压通道 |

通道宽 128 世界像素，起手按玩家当时位置选择并冻结，偏移最多约 180 像素。准备时间约 1.8–2.1 秒，足够以 245 像素/秒步速移入；释放中不追踪玩家重新选位。没有绘制任何通道标签或边框，使用雷云、魂链、烟、水和光缎中的自然空隙识别。

近战斧光、剑气扩大到约 330×130；Boss 冲刺加长到 440；秦广王判印由空中压下；九头虫从口部发出五路毒液；龙王召出三根 240 高的水柱；托塔天王从手中掷出三枚大型火轮。普通远程也从武器或口部发射，轨迹朝向起手时锁定的位置。

判定与准备、释放共用保存的几何状态。仅天空攻击及真实飞行走廊扩展存档高度上限，普通斩击不获得额外高度；旧存档中已起手的旧招保留原有范围。本轮不改生命、伤害、评分和挑战资格。

美术来自内置 image_gen，选用资源、提示词、透明归一矩形与 SHA 位于 `assets/boss-fx-v13/`。素材贴地/运动来源、角色层级、实战安全带与无边界绘制检查在 `tools/verify-skill-origins.cjs`；运行截图和检查结果在 `evidence/skill-origins/`。截图包含控制场景，真实键盘移动验证另存 `live-*.png`，不等同于自然通关或真人评价。
