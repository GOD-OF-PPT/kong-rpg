# 章末 Boss 血量调整

2026-10-30，用户反馈 Boss 容易被快速击败，要求增加血量。五个章末 Boss 改为按章节递增的耐久曲线：

| Boss | 原血量 | 新血量 |
| --- | ---: | ---: |
| 巨灵神 | 300 | 600 |
| 秦广王 | 318 | 800 |
| 九头虫 | 336 | 1000 |
| 东海龙王 | 354 | 1250 |
| 托塔天王 | 372 | 1500 |

普通与挑战使用相同血量表，避免在既有强化行为上叠加隐含倍率。普通兵和小首领仍使用原有血量，玩家伤害、Boss 技能伤害、预警和评分规则沿用当前实现。血量表在 `K.BOSS_MAX_HP`，房间生成与血条从相同的守关者定义读取。

schema12 旧存档根据保留的 Boss `maxHp` 识别之前的已知血量表；剩余生命按原比例映射到新上限并向上取整，血量为 0 的 Boss 保持死亡。只接受旧上限内的合法生命值；重新保存后使用新上限，后续读取不会重复放大。存档中的阶段、已完成关卡、击杀记录和人物状态保持原有恢复流程。

`node tools/verify-boss-health.cjs` 检查两种难度的五个 Boss、真实伤害、击杀只结算一次、当前存档恢复和 20 份升级前存档的比例衔接；原始旧存档在 `evidence/boss-health/old-saves.json`。战役检查验证十五关奖励与胜利流程，HUD 检查使用实际 Boss 上限计算半血数字。

该调整增加可承受伤害量，实际战斗时长仍取决于构筑、命中率和走位；固定伤害命中次数不作为真人难度或通关时长的证明。
