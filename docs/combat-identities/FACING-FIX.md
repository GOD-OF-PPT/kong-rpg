# 敌人施法朝向修正

2026-10-30 用户反馈怪物背对角色施法。本轮只处理朝向；用户已要求忽略腾云骨问题，没有修改该舍利、二段跳或换关规则。

原始五区敌人动作图没有统一朝向：云上弩手、盾卫整行向右，部分近战起手向左但释放向右，水下鱼卫和蚌妖的释放没有反向。旧 `motionActor` 统一按逻辑 face 翻转，造成模型背向当前目标，或切换姿势时自行转身。

逐帧检查源图后，在 `MotionFrames` 与归一记录中保存原始 `facing`，绘制时合并原始方向与模拟方向。同步更新生成脚本，重新生成数据不会丢失方向信息。没有重新生成美术图片，没有改动角色动作。

敌人在待机决策时朝向当前目标；技能起手后保持已经预告的方向和命中框，不会因玩家绕背而中途追踪转向。分身诱敌规则保留。

`node tools/verify-enemy-facing-rules.cjs` 检查五区左右目标与起手锁定；`node tools/verify-enemy-facing.cjs` 通过实际 Renderer、Canvas 变换检查普通兵和小首领的待机、起手、释放、收招。视觉核对图和运行截图在 `evidence/cloud-facing/`，该目录早期的 cloud-contract 仅为排查记录，不构成腾云骨缺陷修复结论。
