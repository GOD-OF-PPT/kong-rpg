# 玩法与美术修正 — 一个矛盾

## 本轮判断

问题：普通敌人已举刀，玩家持续轻棍却不断延后它的状态计时，预警不能可靠对应攻击。玩家观察到的意图失去价值。选择修正此问题；未增加关卡、敌人、舍利目录、血量或地图几何。

专业补充工作：先寻找推翻方案的局面，而不是预设读招必然更好。原始材料是实际模拟与渲染代码、输入回放、敌人阶段、有效碰撞盒、声音事件和未剪辑录像；不是通过率汇总。方法是固定第一处执刃魔兵、配对初始距离/生命/构筑、比较策略、独立禁用分身输入，并记录动作/画面/声音时间线。结果由可重放的版本与行为差异支持；真人理解和重开意愿需外部玩家另验。

## 改动与取舍

- 普通敌人在蓄力/攻击阶段继续计时，轻棍闪白不再冻结招式；空闲阶段仍有轻微受击停顿。
- 第三棍、踩踏与下劈可以打断普通敌人蓄力，短时不可连续打断。普通轻击仍造成原伤害，没有突然免疫、额外血量或强制技能检查。
- 100ms左右的观察间隔可选择跳避后返击；照影分身可花定力、诱敌并绕背。保留近乎极限距离持续打棍也能无伤的反例，不能把结论泛化成“读招处处优于连按”。
- 悟空使用统一锚点的出棍、收招、跳、落、闪避与受伤姿态；普通敌人用举刀/挥刀姿态分开预警与生效。友方分身染青，残影限制到三条，教学条下移，避免遮住近身刀光。
- 普通敌人与无天的刀光使用模拟层同一个攻击盒，原碰撞尺寸不变。命中闪白只作用于精灵透明像素，修正原先覆盖背景的矩形。落点阴影寻找下方实际平台。
- 三境原有背景增加低对比树林、水纹和残柱的层次；不改变落脚面或加入装饰碰撞。

## 对照条件和可证伪边界

`tools/experiments/encounter.cjs`：第一处实际执刃魔兵，种子LOTUS-1025/0318/0916，初始x380/390，生命12/50/100，65定力；敌人冷却统一设为0，以暴露已准备攻击的场景。隔离其他敌人和阵眼是实验设置，不声称自然整局。三种种子在该第一遭遇上相同，不能算独立统计样本。

hold：不移动、按住棍击。read：每100ms采样，使用上一采样的可见阶段，跳避或分身绕背，鼠标返向。不是人类反应速度模型，也没有输入延迟总体结论。

原版e5dc0b5中，hold在两处距离均无伤；新版x390中hold受12点伤害，生命12时失败；读招跳避无伤、用时约1.408秒；照影约0.933秒但消耗50定力。x380仍存在hold无伤的有效间距。两种构筑都可成功，区别是时间/资源/动作，不能宣称同样有趣。

独立移除：read-no-clone在实验调用处禁止clonePressed，发行版没有该开关；策略转用跳避，仍无伤但更慢。说明分身缩短窗口所需时间、消耗资源，但不是强制钥匙。该实验包含策略适应，不能当作“同一输入下的纯单变量因果效应”。

`replay.cjs`逐动作重放，核对成功、伤害、生命、时长；`browser-encounter.cjs`用有效导入样本建立同局面，再通过真实浏览器键鼠操作录像，不直接写运行状态。记录声效事件调用时刻，但不能替代真人听觉质量评审。

## 迭代与保留

最初x350处敌人未进入攻击距离，hold无伤不构成问题证据；改用配对x380/390、统一准备冷却并保留两侧结果。早期控制器落地后背向敌人导致超时，修正为鼠标返向，没有把脚本错误当敌人设计问题。

此前完整开发试作已保存在codex/full-game-delivery的968f6b7，为未验收工作；在活动目标被收窄后未合入本分支。本轮从e5dc0b5重新提取最小修正，不能把试作v2材料当本轮交付。

整局控制器曾在高台下连续延长空格按住时间，缺少新的按下边沿，最终被飞弹击败。保留失败记录，修正脚本为每次新跳明确松开再按；没有据此削弱敌人或修改地图。

## 未成立的结论

没有真人首次游玩、危险理解、主动改变打法或自愿重开的证据。没有取得原剧可核实片段；本轮动作均为游戏原创，不声称原剧复刻。不宣称完整游戏已开发完毕。外部试玩观察步骤见PLAYTEST.md。
