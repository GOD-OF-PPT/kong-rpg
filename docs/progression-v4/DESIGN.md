# v4 制作目标：蓄势、成法、破关

基线：`59752899d817e32e2e2e5b82f1b9a5467d2a954b`（v3.0.2），分支 `codex/ultimate-rewards-bosses-v4`。保留三境平台路线、六阵、无天终战和当前架构。

孙悟空的体验：通过近身棍法挣来战意，用积蓄的大招和沿途选择的法门，主动打破不同守关者的节奏。

- **法天象地（R）**：战意100才能释放。命中和破阵积攒，不靠原地等冷却。起势0.20秒、64伤害宽幅棍浪，破盾并清除范围内敌弹；前0.32秒护体，随后收招仍有风险。强化“如意余威”追加第二记32伤棍浪；走位与释放时机仍重要。
- **奖励**：保留舍利三槽。另有局内根骨、招式强化与Q限次符术，不占舍利槽。每次仍只选一项，始终保留调息；同一符术槽被新符替换，失败清空全部局内成长。奖励须改变攻击距离、闪避站位、分身落位或大招使用时机。
- **独立关卡Boss**：三境末段新增镇山魈王、渡厄灯魁、缄愿法使。冲撞/震地、散焰/索灯、封愿光柱/低钟浪分别考察纵向避让、弹道与诱敌、横纵判断。预告与伤害共用几何，收招可自由输出。三位为游戏原创守阵者，不冒称原剧角色。最终无天维持独立战斗。

先写下通过标准：R确实需要战斗积攒且每次只结算一次，空放不自动返还战意；不同奖励在相同种子场景中改变操作结果；三境Boss必须可见、可伤、可反制，未击败不能过门，击败不提前触发胜利；完整键鼠流程能走到无天结算。若普通连按在所有Boss预告中都稳定无伤，或所有强化仅改变结算数字，需要修改。

存档与旧版：新规则使用schema4及独立键，保留完整v3.0.2入口、原有v1/v2入口与旧键。暂停、符术剩余次数、成长、战意、进行中的Boss招式和大招都必须可导出导入。发行HTML继续内嵌资源，实际验证HTTP与断网file入口。

美术：新Boss使用原创像素图集，预告为紫粉，己方符术为青，法天象地为金白；Canvas表现动作与危险，DOM呈现战意、符术与奖励解释。以实际战斗尺寸截图与连续操作录像检查，不能以概念图验收。
