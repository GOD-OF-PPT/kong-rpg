# 怪物技能美术资源

两次使用内置ImageGen，实际提示词和调用源码保存在IMAGEGEN-CALLS.json。源图与最终图集均归仓库，不需要运行时生成接口。

- assets/enemy-vfx-v12/contacts-source.png：6列4行，金属、碎石、墨链、毒液、水花、雷击、火焰、风压共8类，每类接触/爆开/消散3帧。小尺寸、不画完整法阵、不画人物背景或大光雾。
- assets/enemy-vfx-v12/materials-source.png：4列4行，弩矢、链节、毒珠、空心火轮、浪峰、泡沫底、水冠、柱身、墨印、塔印、石裂、尘屑、雷叉、塔光、风带和薄刃月。按实际用途横向或竖向排列；大范围靠重复/裁切构成，不拉长材质。
- contacts.png与materials.png：固定64像素单元，预乘alpha的Lanczos归一。每组接触动画使用相同缩放，保持材质碎片尺寸一致；取源alpha裁切，透明背景RGB不会成为色块。裁切、尺度和源SHA在normalization.json，40个登记帧在src/enemy-effects-data.js。污潮用浪峰的缓存青绿染色变体；物理轮廓与毒扇球形弹分开。

提示词的共同约束：真正透明RGBA；较大、清楚的像素簇；限制高光，接触中心小；充足隔离空白；没有文字、面板、网格、人物、巨大填充圆盘或通用紫色椭圆。源图展示不作为验收，实际游戏尺寸、叠层和动态释放另有记录。
