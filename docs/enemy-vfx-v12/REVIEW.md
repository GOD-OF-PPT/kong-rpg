# v12.1.0 怪物技能表现

基线bf8b57f87f310d57fc17a239311aec4e103e3cce / v12.0.0，分支codex/v12-enemy-skill-vfx，起步干净。用户指出怪物技能和打击效果粗糙。核心问题是既有动作之上仍共用拉伸贴图、叠画旧特效，无法表达材质、接触与节奏。

## 实现

DESIGN.md记录19招的起手/锁定/释放/命中/收尾关系。保留原招式数量、地图、伤害、时序、追击及资格；主角规则也不变。

- 物理斩击使用刃轨与接触火星，地震使用分段石裂；冲刺仅强调移动身体，不把整条旧路径画成持续危险实体。
- 风弩/毒扇分别使用弩矢/毒珠；低潮为短浪峰，火轮是空心滚动实体。亮弹体裁切在原碰撞框里，不用大光晕填满弹间空隙。
- 地府链节与墨印、龙宫水柱/泡沫/雷叉、天宫塔印/塔光有不同的轮廓和分段节奏；保留共同的细危险边界，不靠颜色单独表达可受伤区域。
- 清除combat-art、celestial-art与campaign-art之间的重复绘制。基线的紫色椭圆并非一层；只换最外层会留下旧图，因此加入明确的modernEnemyFX分派，历史未识别效果保留原路径。
- K.damage仅在成功结算时生成材质接触；位置取伤害盒与角色交集。无敌/闪避没有假受伤爆点。声音按金属、碎石、墨链、毒、水、雷、塔光、火、风区别合成瞬态，仍使用本地WebAudio，不引入远程音源。
- 多个同名敌人在场时，以原锁定盒找到攻击者，避免引用死去/远处同名士兵的错误朝向。恢复存档时从原有source识别材质；新效果不要求额外保存字段。

新增资产与提示词见PROMPTS.md；只有两张归一图集进入发行，图片与脚本仍内嵌。v12/schema12存档继续兼容，无需新开旅程。
