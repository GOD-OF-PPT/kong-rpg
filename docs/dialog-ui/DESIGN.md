# 游戏弹窗设计依据（v2.1）

基线 main / cb4cdfa，工作区干净；开发分支 codex/game-dialog-art。本轮只改界面表现、阅读组织与菜单输入，不改地图、战斗、舍利效果或存档规则。

## 调研与取舍

- [Hades / Boons of Aphrodite 画面](https://interfaceingame.com/screenshots/hades-boons-of-aphrodite/)：实际在浏览器查看静态截图。观察到神祇形象、象征纹样与奖励内容形成层级，选项可直接比较。借鉴“物件身份先于说明”，本项目用云骨、影珠、棍段等原创图标和经卷，保留三选一。不照搬其素材、布局或希腊纹样。
- [Blasphemous / Options 画面](https://interfaceingame.com/screenshots/blasphemous-options/)：实际查看静态菜单。观察到左侧主题造型、纵向选项和单个菱形焦点，低优先级内容不与主要操作争夺注意。转化为悟空立像旁的暂停选择；继续/手记/主菜单为主，声音与存档为次。
- [Supergiant 开发说明](https://www.supergiantgames.com/blog/get-pumped-for-the-beefy-update/)：开发者明确将祝福界面改进与管理局内能力联系；本文只以此支持界面服务构筑决策，不推导未经验证的玩家评价。
- [Xbox XAG112 导航](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112)：稳定导航方式、可预测焦点。落实为方向键/Tab/Enter、保持1/2/3速选、手记返回暂停原焦点、模态外元素inert、设置滑杆保留左右键、Esc从设置正常继续。
- [Xbox XAG102 对比度](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/102)：重要文字与背景应可辨。落实为纸面深墨字、暗场浅金字、纸边不承载说明；以实际纹理样本测量小字对比。不是对全部XAG的合规认证。

以上截图来自界面收藏站，属于可直接观察的静态画面、二手收录；没有声称亲玩参考游戏、测得其动画时长或访谈作者。交互推论为本项目设计判断。

## 各类弹窗

|界面|新的表现与交互|
|---|---|
|开篇、尾声|留出暗场，朱绶莲章与章回标题；行程路线、正文、下一步分层。尾声供灯完整留在边界内|
|初始舍利、借灯、过境|悬挂经卷承载实物图标；名称→打法→代价。生命/定力在奖励之前，已携带构筑在之后|
|替换舍利|上方单独展示即将取得的舍利，下方明确是已携带物；“放下此物”和返回均清楚，Esc不改变构筑|
|暂停|悟空立像配纵向菜单。焦点有菱形和亮带；声音/屏震和导入导出降低视觉权重|
|手记|真正的线装书双页，六条短课目，避免说明跨越书脊或压到纸边|
|失败、胜利|独立全幅结算，失败偏赭红、胜利偏暖金；大结果、小统计、构筑与重开动作有层级|
|历史、旧旅程说明|因缘簿与章回排版，沿用同一金/墨/朱色；读完有明确返回|
|临时提示|边缘的短墨条，无中央通知框；模态提示移到顶部，避开底部操作提示|

范围为当前v2.1全部11种模态状态及奖励的中途/过境变体。浏览器原生文件选择器由操作系统提供；保留的legacy-v1.html是旧版本存档兼容入口，维持旧貌。

## 实际材料与规范

ImageGen内置工具生成三张原创PNG：assets/ui-v3/pilgrim-scroll.png、relic-icons.png、field-folio.png。原图与透明alpha全部保留；提示词见PROMPTS.md。沿用现有悟空图集和供灯素材，不新增角色或装备。

世界仍在960×540 Canvas，所有标题、说明、按钮与反馈文字在DOM。标题用本地宋体，功能说明用本地雅黑；不让生成图承载文字。材质色为旧纸、深墨、锈金、朱绶，与“劫后佛国”相连。装饰只放在外围，保证阅读区安静。

入口约180ms轻入场，仅改变不透明度和5px位移。悬卷焦点微抬；系统偏好减少动态时取消两者。菜单移动/确认用本地低音量短音，不加持续闪烁。鼠标与键盘共用同一焦点，避免两枚选择标记同时出现。

## 调整记录

1. 第一版经卷说明挨近纸边：按实际纸张范围加内边距、压缩重复措辞，保留效果与代价。
2. 生成的书页虽然已解码，原始大dataURL未成为有效CSS变量：改为按实际显示尺度生成纹理，再核对computed style和截图。
3. 书脊与纸边曾压到手记：改短课目与两页留白；编号改中文，保持完整阅读。
4. 同时出现hover与键盘双标记：统一为实际focus；鼠标移动切换同一个焦点。
5. 生成焦点菱形混入按钮可访问名称：按钮设置独立aria-label，装饰不改变名称。
6. Windows短暂锁定发行HTML导致原子替换失败：构建只对EPERM/EACCES/EBUSY短暂重试，失败保留旧文件，不删除可用入口。

外部真人的审美认可与导航理解尚未取得；当前只有开发侧画面审看和真实浏览器操作证据，不能据此声称所有玩家都更喜欢。
