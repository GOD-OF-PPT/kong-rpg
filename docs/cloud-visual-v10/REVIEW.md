# v10.0.3 云上实机美术修订

基线 `4fc77ec9fe29803565ccce054a01edf3bec6b93c` / v10.0.2，分支 `codex/v10-cloud-visual-acceptance`，开始工作树干净。用户截图来自当时打开的v10.0.1查询URL，但前一轮的v10.0.2也仍然存在截图指出的视觉问题。本轮以真实画面重新验收，未把文件齐全当成视觉契合。

## 原始问题与修改

|实机观察|原因|修订与取舍|
|---|---|---|
|云上仍像地面山道，佛塔、砖墙和悬平台不统一|战役背景/地形与旧版mapTheme装饰混用，顶部留白另加白线|生成云海背景、浅玉阶、连续悬岩、风幡、云门与灯。云上三关单独选材，去掉佛塔与白线，平台实顶对齐落脚Y；其余章节沿用自己的素材|
|金色方块像不明图标，第二个与巡逻怪重叠|把UI卷轴缩成世界对象，只有极小光圈，无名字|改为兵器托座，竖棍/回环棍轮廓，DOM写“秘技＋招式名”，接近显示F参悟。初始x改为210、310，保留原有stage:index资格ID；拾取同时移除对象和文字|
|撑天坠击一直是同一身体姿势，落地效果像重复贴图|旧pole单格贯穿全程，七张quake贴满底部|ImageGen同批八姿势中选四式：立棍/撑升/下坠/落地；按原动作时间窗切换，动态棍连接握点与地面。1.02秒真实结算后才有接地冲击，低位压力环覆盖当前视口，角色仍可见|
|棍阵像被压扁的光片和堆叠棍条|同一方形spin-ring拉宽，程序段重复叠绘|一根可见棍绕身投影，轨迹分角色后/前两层，中间透明。五段12伤害、320×43范围、32定力与11秒冷却保留，K仍可取消|
|大量边缘有额外台阶、闪烁和碎点|960×540被非整数nearest放大；大原图nearest缩小；旋转特效禁插值|CSS改为auto，仅对大图降采样、旋转/缩放效果启用高质量插值；新资源用预乘alpha Lanczos归一。没有整屏模糊或改掉原生世界坐标，像素色块仍存在|

实际素材与完整提示词见 [PROMPTS.md](PROMPTS.md)，源图/归一图集位于 `assets/cloud-visual-v10/`。八格身体姿势共用0.23比例，脚底锚点80/112，各格握点单独记录以接动态棍；源SHA、裁切、透明度与尺寸在normalization中。云岩初稿每128像素重复成牙齿状，未作为最终稿；再生成宽768像素连续悬岩后替换，保留各次原始图。

## 实际验证

- `before-comparison`：从git保存的v10.0.2原入口，在相同1440×1000、DPR1.25下经公开菜单/实际键鼠完成相同拾取与两式施放，留存修前录像和原生阶段帧。nearest强制放大与无名对象两项失败保留。
- `final-http`：真实新开旅程，走近两项秘技、F参悟、B换技、C完整施放、暂停、J输入隔离、施放中导出/导入。坠击花45定力、只结算一次；棍阵花32定力，实际五段/收招保留。八个阶段画面来自实际Renderer.draw观察，不是拼造动画帧。
- `catalog-http`：59张内嵌PNG、300个登记帧实解码/非空/边界检查，352个受控渲染覆盖十五关普通/挑战、三角色与全部首领招式，零运行异常。受控样张与自然操作证据分开。
- `viewports/review.json`：1366×768/DPR1、1773×1001/DPR1、1920×1080/DPR1.25、1440×1000/DPR2真实开始画面。两项标签均在世界内，中心对齐误差小于0.02 CSS像素，指针中心仍映射480/270，原生Canvas仍960×540。
- `rules.json`、`campaign-rules.json`：原机制/存档/十五关/挑战资格回归通过，输出到本轮目录，未覆写旧证据。

关闭5188服务、确认无监听后，全新断网会话直接打开正式ZIP解压入口：`final-file` 拾取/换技/两式完整施放/施放中导出恢复通过；`dual-mode-file` 三角色普通/挑战实际键鼠检查59项通过，`catalog-file` 同样覆盖300帧和352受控场景。三项离线检查均为零HTTP请求、零运行异常。HTTP对应真实角色操作58项通过。入口SHA256为 `249bfb53be5263c95ce973f578569724d72be6d23c1cf1527274ec1e540fa7b3`，HTTP、ZIP解压和三项离线记录完全一致。记录见 `evidence/cloud-visual-v10/summary.json`、`package.json`。

修前/修后两式录像均使用960×540 Canvas captureStream/VP9，ffprobe实际约22秒、651至657个帧包，连续保留中间冷却和菜单操作；关键阶段不是离线拼图。四种viewport/DPR的DOM标签与指针映射均通过。验收后恢复IP服务并实际请求当前v10.0.3。原有十二次十五关自然整局属于v10.0.1，本轮没有将其改名算作v10.0.3通关。

初次新操作录像在旧位置拾完卷直接施法，被靠近的敌人真实打断而超时。验收改为按正常A键退回安全起点后施法，再独立检查敌人/普通挑战战斗；没有加无敌、缩短起手、改变敌招来迎合脚本。构建还在首次云门图集底部越界时正确拒绝发行，扩充图集画布后通过。

## 结论边界

已按1–2张一批查看首屏、云上三个关卡、关门、两式各阶段、不同缩放窗口，以及普通/挑战动态画面。现在世界对象有名称与操作提示、云上前景使用统一材料、棍法有分段动作，画面边缘的额外采样锯齿减少。该结论是开发者视觉与运行证据，不是外部真人认可；没有宣称彻底没有任何像素阶梯，也没有进行真人辨识访谈。其它章节没有整体重绘，现有角色仍以关键姿态加程序动画为主。
